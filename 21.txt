REPLAY-СИСТЕМА: ПЕРЕСМОТР МУЛЬТИКА С ДРУГИМ РАКУРОСОМ
═══════════════════════════════════════════════════════

Введение
────────

Просмотр анимированного мультика — это одноразовый опыт? В классическом кинематографе пересмотр permett al spectateur de remarquer des détails manqués. Но интерактивный мультимедиа-проект на Canvas даёт нечто большее: возможность буквально смотреть тот же эпизод под другим углом. Replay-система проекта «Пирожки с нуля» реализует именно это — три уникальных пресета камеры, каждый из которых раскрывает сцену по-новому.


Зачем смотреть второй раз
──────────────────────────

Первый просмотр мультика — это эмоции, сюжет, общий смысл. Зритель поглощает историю целиком, не обращая внимания на детали окружения, мимику персонажа, микродвижения предметов. Второй просмотр — это возможность:

- Увидеть то, что было за кадром или на периферии
- Оценить детализацию окружения: структуру теста, текстуру корочки пирожка
- Обратить внимание на тонкие переходы mood-системы между сценами
- Пережить историю заново, но с уже знакомым сюжетом
- Оценить качество анимации и детализацию каждого кадра

Именно для этого создаётся Replay-система. Она не просто перезапускает мультфильм — она переосмысливает визуальный опыт через три разных режима камеры.


Три пресета: closeup, wide, drama
─────────────────────────────────

Каждый пресет — это набор настроек камеры, определяющий zoom, позицию и характер движения:

CLOSEUP (подробно):
- Camera zoom: 1.8x — крупный план на детали
- Фокус на руках персонажа, текстуре теста, процессе лепки
- Широкая диафрагма: размытие фона (если реализуем blur)
- Mood: спокойный, сосредоточенный
- Подходит для тех, кто хочет изучить технику лепки пирожков

WIDE (обзорно):
- Camera zoom: 0.7x — панорамный вид
- Вся кухня целиком: стол, полки, окно, детали интерьера
- Глубина пространства: видны все слои параллакса
- Mood: уютный, тёплый
- Идеально для первого знакомства с атмосферой проекта

DRAMA (кинематографично):
- Camera zoom: 1.0x — стандартный, но с драматическим движением
- Медленные кадры: зум во время ключевых моментов
- Контрастное освещение: усиление теней
- Mood: напряжённый, эмоциональный
- Акцент на эмоциях персонажа, а не на деталях кухни

Каждый пресет определяется объектом с параметрами:

const presets = {
  closeup: { zoom: 1.8, focusY: 0.6, blur: 3, speed: 0.8 },
  wide:    { zoom: 0.7, focusY: 0.5, blur: 0, speed: 1.2 },
  drama:   { zoom: 1.0, focusY: 0.4, blur: 1, speed: 0.6 }
};


Как пресеты меняют camera zoom, mood, light
───────────────────────────────────────────

При переключении пресета происходит плавная интерполяция всех параметров:

1. Camera zoom: анимация от текущего значения к целевому за 600мс
2. Camera position: смещение центра кадра к фокальной точке
3. Mood: изменение палитры фона через drawMoodBg()
4. Light: регулировка яркости и контрастности слоёв

closeup создаёт intimacy — зрителя как будто приглашают к столу, он видит каждую деталь. wide создаёт контекст — кухня как живое пространство. drama создаёт кинематографическое ощущение — каждый кадр как кадр фильма.

Визуально это реализуется через модификацию контекста Canvas:

function applyPreset(ctx, preset, progress) {
  const p = presets[preset];
  const current = lerp(currentPreset, p, progress);
  ctx.save();
  ctx.translate(W/2, H/2);
  ctx.scale(current.zoom, current.zoom);
  ctx.translate(-W/2 * current.focusX, -H/2 * current.focusY);
}


Кнопки replay на экране финала
──────────────────────────────

В конце каждой сцены отображаются три кнопки replay:

┌─────────┬──────────┬─────────┐
│ CLOSEUP │   WIDE   │  DRAMA  │
│  🔍     │   🌍     │   🎬    │
└─────────┴──────────┴─────────┘

Каждая кнопка — это прямоугольник с градиентной заливкой и текстом. При наведении — подсветка, при клике — перезапуск текущей сцены с выбранным пресетом. Кнопки расположены внизу экрана, не перекрывают основной контент, и достаточно велики для touch-интерфейса (минимум 48x48px).

Реализация кнопок:

function drawReplayButtons(ctx) {
  const buttons = ['closeup', 'wide', 'drama'];
  buttons.forEach((name, i) => {
    const x = W/2 - 120 + i * 100;
    const y = H - 80;
    drawButton(ctx, x, y, 80, 40, name.toUpperCase());
  });
}


Психология повторного просмотра
───────────────────────────────

Повторный просмотр — это не просто дублирование опыта. Это:

- Мнемонический эффект: мозг запоминает первый просмотр и автоматически сравнивает
- Эффект предвкушения: зритель уже знает сюжет, поэтому наслаждается процессом
- Детектирование паттернов: мозг начинает замечать повторяющиеся элементы
- Эмоциональное удовлетворение: знакомая история вызываетcomfort

Closeup-режим подходит для аналитического зрителя, который хочет понять «как это сделано». Wide-режим — для ценителя атмосферы. Drama — для того, кто хочет пережить эмоциональную арку заново.

Replay-система превращает одноразовый просмотр в многократный опыт, каждый раз раскрывая новый слой проекта «Пирожки с нуля».


Заключение
──────────

Replay-система — это не просто техническая фича, а осознанное решение, расширяющее жизненный цикл мультимедийного продукта. Три пресета камеры дают три разных чтения одной истории, а психологическая механика повторного просмотра создаёт дополнительную ценность для зрителя. В проекте «Пирожки с нуля» это превращает короткий мультфильм в полноценный интерактивный опыт.
