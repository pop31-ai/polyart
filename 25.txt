ПРОГРЕСС-БАР И ВИЗУАЛЬНАЯ ОБРАТНАЯ СВЯЗЬ
══════════════════════════════════════════

Введение
────────

Прогресс-бар — один из самых недооценённых элементов пользовательского интерфейса. В контексте анимированного мультика он выполняет не только техническую функцию (показать, сколько осталось), но и психологическую: даёт зрителю ощущение контроля и предсказуемости. Проект «Пирожки с нуля» реализует продуманную систему прогресс-баров, интегрированную с таймером и mood-системой.


Полоса прогресса: ширина = T/TOTAL × 100%
─────────────────────────────────────────

Основная формула прогресс-бара элементарна:

progress = currentTime / totalTime

Где currentTime — текущее время воспроизведения, totalTime — общая длительность мультика. Результат — число от 0 до 1, которое преобразуется в проценты:

const percentage = (currentTime / totalTime) * 100;

CSS-реализация полосы:

.progress-bar {
  width: 100%;
  height: 6px;
  background: rgba(255,255,255,0.1);
  border-radius: 3px;
  overflow: hidden;
}

.progress-fill {
  height: 100%;
  width: 0%;
  transition: width 0.3s ease-out;
  background: linear-gradient(90deg, #FFB864, #E67E22);
}

Прогресс-бар размещён в верхней или нижней части экрана, не перекрывает контент, и достаточно тонок (6px), чтобы не отвлекать от мультика, но заметен, чтобы зритель всегда знал, где он.


CSS transitions для плавности
─────────────────────────────

Прогресс-бар не «прыгает» — он плавно двигается благодаря CSS transition:

.progress-fill {
  transition: width 0.3s ease-out;
  will-change: width;
}

Параметр ease-out создаёт эффект «инерции»: полоса слегка замедляется при приближении к целевому значению. Это делает движение более естественным и менее роботизированным.

Альтернативный подход — анимация через requestAnimationFrame:

function animateProgressBar(target) {
  const start = currentWidth;
  const diff = target - currentWidth;
  const startTime = performance.now();

  function step(now) {
    const elapsed = now - startTime;
    const progress = Math.min(elapsed / 300, 1);
    const eased = 1 - Math.pow(1 - progress, 3); // ease-out cubic
    currentWidth = start + diff * eased;
    bar.style.width = currentWidth + '%';
    if (progress < 1) requestAnimationFrame(step);
  }
  requestAnimationFrame(step);
}

Оба подхода дают плавное движение. CSS transition проще в реализации, requestAnimationFrame даёт больше контроля.


Градиентная заливка
───────────────────

Прогресс-бар в проекте «Пирожки с нуля» использует градиентную заливку, соответствующую mood-системе:

cheerful: linear-gradient(90deg, #FFB864, #FFDC96)
- Тёплые оранжевые тона
- Ассоциация: солнечное утро, радость

dramatic: linear-gradient(90deg, #9B59B6, #6C3483)
- Фиолетовые тона
- Ассоциация: напряжение, важность момента

romantic: linear-gradient(90deg, #FF96B4, #C86482)
- Розовые тона
- Ассоциация: нежность, забота

neutral: linear-gradient(90deg, #C4A882, #8B7355)
- Коричневые тона
- Ассоциация: процесс, работа

Градиент обновляется при смене mood:

function updateProgressBarColor(mood) {
  const colors = moodColors[mood];
  progressFill.style.background =
    `linear-gradient(90deg, ${colors[0]}, ${colors[1]})`;
}


Интеграция с таймером
─────────────────────

Прогресс-бар напрямую привязан к таймеру мультика:

const totalTime = episodes.reduce((sum, ep) => sum + ep.duration, 0);
let currentTime = 0;

function updateProgress(deltaTime) {
  currentTime += deltaTime;
  const progress = Math.min(currentTime / totalTime, 1);
  bar.style.width = (progress * 100) + '%';

  // Обновляем текущий эпизод
  const elapsed = currentTime;
  let accumulated = 0;
  for (const ep of episodes) {
    accumulated += ep.duration;
    if (elapsed < accumulated) {
      currentEpisode = ep;
      break;
    }
  }
}

Таймер обновляется каждый кадр через requestAnimationFrame. Прогресс-бар — это визуальная проекция внутреннего таймера на экран.


Psychological effect: «сколько осталось»
─────────────────────────────────────────

Прогресс-бар влияет на восприятие зрителя:

- Эффект завершения: когда полоса приближается к 100%, зритель испытывает предвкушение финала
- Эффект контроля: зритель видит, сколько осталось, и может принять решение (пересмотреть, перемотать)
- Эффект погружения: непрерывное движение полосы создаёт ощущение «потока времени»
- Эффект вознаграждения: заполнение полосы визуально «награждает» за просмотр

Исследования UX показывают, что пользователи предпочитают видеть прогресс даже в автоматически воспроизводимом контенте. Отсутствие индикатора прогресса вызывает тревогу и снижает вовлечённость.


Прогресс внутри каждой сцены: дополнительная полоса
──────────────────────────────────────────────────

Помимо основного прогресс-бара (общий мультфильм), проект добавляет мини-прогресс для каждой сцены:

┌─────────────────────────────────────┐
│ ████████████░░░░░░░░░░░░░ 45%      │  ← общий прогресс
│ ████████████████████░░░░░ 78%      │  ← прогресс сцены
└─────────────────────────────────────┘

Мини-прогресс показывает прогресс текущего эпизода:

const sceneProgress = (sceneTime / currentEpisode.duration) * 100;
miniBar.style.width = sceneProgress + '%';

Два прогресс-бара работают в тандеме: основной показывает общий ход, мини — детали текущего эпизода. Это создаёт многоуровневую обратную связь.


Заключение
──────────

Прогресс-бар в проекте «Пирожки с нуля» — это не просто полоска на экране. Это продуманная система визуальной обратной связи, интегрированная с таймером, mood-системой и психологией восприятия. Два уровня прогресса (общий и сценовый), градиентная заливка и плавные переходы создают интерфейс, который помогает зрителю ориентироваться в мультфильме и усиливает эмоциональный опыт просмотра.
