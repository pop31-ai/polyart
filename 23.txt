СМЕШИВАНИЕ ЦВЕТОВ И НАСТРОЕНИЙ В CANVAS
════════════════════════════════════════

Введение
────────

Цвет — самый мощный инструмент передачи настроения в визуальном искусстве. В анимированном мультике на Canvas управление цветом становится ключевым механизмом создания атмосферы. Проект «Пирожки с нуля» реализует mood-систему, которая динамически управляет палитрой, градиентами и освещением каждого эпизода. Этот подход превращает рисование на Canvas из простого «закрашивания» в полноценную цветовую композицию.


Градиенты: linear и radial
──────────────────────────

Canvas предоставляет два типа градиентов, оба используются в проекте:

Linear gradient — линейный переход цвета между двумя точками:

function createLinearBg(ctx, color1, color2) {
  const grad = ctx.createLinearGradient(0, 0, 0, H);
  grad.addColorStop(0, color1);
  grad.addColorStop(1, color2);
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, W, H);
}

Radial gradient — радиальный переход от центра к краям:

function createRadialBg(ctx, centerX, centerY, color1, color2) {
  const grad = ctx.createRadialGradient(
    centerX, centerY, 0,
    centerX, centerY, Math.max(W, H) * 0.7
  );
  grad.addColorStop(0, color1);
  grad.addColorStop(1, color2);
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, W, H);
}

Linear используется для фона сцены (вертикальный градиент — небо к земле). Radial — для точечных эффектов: свет из окна, подсветка рабочей зоны, виньетирование по краям кадра.


Mood-система
────────────

Каждая сцена мультика имеет mood-состояние, определяющее цветовую палитру:

cheerful (весёлое):
- Основные цвета: #FFB864 → #FFDC96 (тёплые оранжево-жёлтые)
- Фон: тёплый, солнечный, «утро на кухне»
- Акценты: яркие, насыщенные
- Чувство: уют, радость, предвкушение

dramatic (драматичное):
- Основные цвета: #1E1E32 → #3C2850 (тёмные фиолетово-синие)
- Фон: контрастный, с глубокими тенями
- Акценты: холодные, приглушённые
- Чувство: напряжение, ожидание, важность момента

romantic (романтичное):
- Основные цвета: #C86482 → #FF96B4 (нежно-розовые)
- Фон: мягкий, рассеянный свет
- Акценты: пастельные, нежные
- Чувство: нежность, забота, домашнее тепло

neutral (нейтральное):
- Основные цвета: #8B7355 → #C4A882 (коричнево-бежевые)
- Фон: сбалансированный, без ярких акцентов
- Чувство: сосредоточенность, процесс

Каждый mood определяется объектом:

const moods = {
  cheerful: {
    bg1: '#FFB864', bg2: '#FFDC96',
    text: '#5A3E1B', accent: '#E67E22'
  },
  dramatic: {
    bg1: '#1E1E32', bg2: '#3C2850',
    text: '#E0D4FF', accent: '#9B59B6'
  },
  romantic: {
    bg1: '#C86482', bg2: '#FF96B4',
    text: '#4A1528', accent: '#E91E63'
  },
  neutral: {
    bg1: '#8B7355', bg2: '#C4A882',
    text: '#2C1810', accent: '#8B4513'
  }
};


Динамическое изменение фона в зависимости от mood
──────────────────────────────────────────────────

Фон не просто «меняется» — он плавно интерполируется между mood-состояниями:

function drawMoodBg(ctx, currentMood, nextMood, progress) {
  const c = moods[currentMood];
  const n = moods[nextMood];

  // Интерполяция цветов
  const bg1 = lerpColor(c.bg1, n.bg1, progress);
  const bg2 = lerpColor(c.bg2, n.bg2, progress);

  const grad = ctx.createLinearGradient(0, 0, 0, H);
  grad.addColorStop(0, bg1);
  grad.addColorStop(1, bg2);
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, W, H);
}

Функция lerpColor интерполирует каждый компонент RGBA:

function lerpColor(color1, color2, t) {
  const r1 = parseInt(color1.slice(1,3), 16);
  const g1 = parseInt(color1.slice(3,5), 16);
  const b1 = parseInt(color1.slice(5,7), 16);
  const r2 = parseInt(color2.slice(1,3), 16);
  const g2 = parseInt(color2.slice(3,5), 16);
  const b2 = parseInt(color2.slice(5,7), 16);
  const r = Math.round(r1 + (r2 - r1) * t);
  const g = Math.round(g1 + (g2 - g1) * t);
  const b = Math.round(b1 + (b2 - b1) * t);
  return `rgb(${r},${g},${b})`;
}


Цветовые переходы между сценами
────────────────────────────────

Переход между эпизодами сопровождается плавной сменой mood. Это создаёт ощущение «цветового монтажа»:

- ПРОЛОГ → ПРОБУЖДЕНИЕ: neutral → cheerful (прогрев цвета)
- ПРОБУЖДЕНИЕ → СМЕШЕНИЕ: cheerful → neutral (фокус на процессе)
- СМЕШЕНИЕ → ФОРМОВКА: neutral → romantic (нежность лепки)
- ФОРМОВКА → ВЫПЕЧКА: romantic → dramatic (напряжение ожидания)
- ВЫПЕЧКА → ФИНАЛ: dramatic → cheerful (радость результата)

Каждый переход занимает 2-3 секунды и совпадает с эпизодным заголовком. Зритель замечает изменение цвета, но не осознаёт его механику — именно так и должно работать color scripting.


Заключение
──────────

Mood-система проекта «Пирожки с нуля» превращает Canvas из рисовальной поверхности в полноценный инструмент цветового повествования. Градиенты, интерполяция цветов и динамические фоны создают атмосферу, которая работает на эмоции зрителя, не требуя от него осознанного внимания к цветовым решениям. Это и есть профессиональный подход к color scripting в анимации.
