ФИЗИКА ЧАСТИЦ: ОТ ТЕОРИИ К ПРАКТИКЕ НА CANVAS
================================================

Введение
--------

Система частиц — это один из самых выразительных инструментов в арсенале аниматора. Сотни маленьких объектов, движущихся по физическим законам, создают эффекты, которые невозможно получить классической анимацией: облака муки, струйки пара, летящие искры. В проекте "Пирожки с нуля" система частиц используется в каждой сцене — от посыпки муки при замешивании до Steam от только что испёкшегося пирожка. Эта статья разберёт теорию и практику создания систем частиц на Canvas.


1. Основные параметры частицы
------------------------------

Каждая частица — это объект с набором свойств, описывающих её состояние в конкретный момент времени:

Положение (x, y). Координаты частицы на Canvas. В начале жизни частица получает начальную позицию, которая обычно совпадает с источником эффекта.

Скорость (vx, vy). Скорость изменения положения по осям X и Y за один кадр. vx = 2 означает, что частица движется вправо на 2 пикселя за кадр.

Ускорение (ax, ay). Изменение скорости. Чаще всего ускорение задаётся гравитацией: ay = 0.1 — частица ускоряется вниз под действием "тяжести".

Время жизни (life, maxLife). Каждая частица рождается с определённым запасом "жизни" (обычно от 30 до 120 кадров). По мере жизни time увеличивается, а opacity уменьшается: opacity = 1 - (time / maxLife). Когда time >= maxLife, частица удаляется.

Размер (size). Начальный размер частицы, который может уменьшаться со временем.

Цвет (color). RGBA-значение или ссылка на палитру.

В классе Particles для "Пирожков с нуля" эти параметры реализованы следующим образом:

  class Particle {
    constructor(x, y, options) {
      this.x = x;
      this.y = y;
      this.vx = options.vx || (Math.random() - 0.5) * 2;
      this.vy = options.vy || (Math.random() - 0.5) * 2;
      this.ax = options.ax || 0;
      this.ay = options.ay || 0.05;
      this.life = 0;
      this.maxLife = options.maxLife || 60;
      this.size = options.size || 3;
      this.color = options.color || '#FFFFFF';
    }

    update() {
      this.vx += this.ax;
      this.vy += this.ay;
      this.x += this.vx;
      this.y += this.vy;
      this.life++;
      return this.life < this.maxLife;
    }

    draw(ctx) {
      const opacity = 1 - (this.life / this.maxLife);
      ctx.globalAlpha = opacity;
      ctx.fillStyle = this.color;
      ctx.beginPath();
      ctx.arc(this.x, this.y, this.size, 0, Math.PI * 2);
      ctx.fill();
      ctx.globalAlpha = 1;
    }
  }


2. Физические силы: гравитация, трение, случайность
----------------------------------------------------

Три базовых силы определяют поведение частиц:

Гравитация. Константное ускорение по оси Y. Создаёт эффект падения:

  particle.ay += 0.05; // гравитация

В "Пирожках с нуля" гравитация используется для имитации падения муки с ладоней пекаря: частицы стартуют с высоты и плавно опускаются вниз.

Трение (friction). Замедление частиц со временем. Реализуется умножением скорости на коэффициент меньше 1:

  particle.vx *= 0.98;
  particle.vy *= 0.98;

Трение необходимо для эффектов, где частицы должны останавливаться: например, крошки пирожка, упавшие на стол, не должны бесконечно скользить.

Случайность (randomness). Добавление случайных отклонений к скорости и ускорению. Без случайности частицы движутся слишком предсказуемо:

  particle.vx += (Math.random() - 0.5) * 0.3;
  particle.vy += (Math.random() - 0.5) * 0.3;

Случайность критична для имитации естественных явлений: ни одно облако муки не состоит из частиц, движущихся строго параллельно.

Комбинация этих трёх сил создаёт разнообразные эффекты:
- Облако муки: низкая гравитация + высокая случайность + среднее трение.
- Пар от пирожка: отрицательная гравитация (вверх) + низкая случайность + низкое трение.
- Искры от духовки: высокая гравитация + средняя случайность + низкое трение.


3. Типы частиц в проекте "Пирожки с нуля"
-------------------------------------------

Проект использует четыре основных типа частиц, каждый со своей физикой:

Мука. Белые частицы размером 2-5 пикселей с высокой прозрачностью. Спавнятся из центра замешивания, имеют низкую начальную скорость и слабую гравитацию. Жизнь: 40-80 кадров. Эффект: облако муки вокруг рук пекаря.

Пар. Белые полупрозрачные частицы размером 8-15 пикселей. Спавнятся из пирожка после духовки, движутся вверх (отрицательная гравитация), быстро увеличиваются в размерах и исчезают. Жизнь: 60-120 кадров. Эффект: Steam от горячей выпечки.

Пузырьки. Полупрозрачные круги разных размеров, появляющиеся в тесте при брожении. Медленно поднимаются вверх, слегка покачиваясь в стороны. Жизнь: 100-200 кадров. Эффект: живое тесто.

Искры. Яркие жёлтые и оранжевые частицы, вылетающие из духовки при открытии дверцы. Высокая начальная скорость, сильная гравитация, короткая жизнь (20-40 кадров). Эффект: жар духовки.


4. Оптимизация: пулинг и ограничение количества
-------------------------------------------------

Система частиц может быстро исчерпать ресурсы браузера. Ключевые методы оптимизации:

Пулинг объектов (Object Pooling). Вместо создания и уничтожения объектов Particles (что нагружает сборщик мусора), используются переиспользуемые массивы:

  class ParticlePool {
    constructor(maxSize) {
      this.pool = [];
      this.active = [];
      for (let i = 0; i < maxSize; i++) {
        this.pool.push(new Particle(0, 0, {}));
      }
    }

    get(x, y, options) {
      let particle = this.pool.pop() || new Particle(x, y, options);
      particle.x = x;
      particle.y = y;
      particle.life = 0;
      this.active.push(particle);
      return particle;
    }

    release(particle) {
      const index = this.active.indexOf(particle);
      if (index > -1) {
        this.active.splice(index, 1);
        this.pool.push(particle);
      }
    }
  }

Ограничение количества. Установка жёсткого лимита на количество активных частиц:

  const MAX_PARTICLES = 200;

Если лимит достигнут, новые частицы не создаются. Это предотвращает "подтормаживание" при длительных эффектах.

Отрисовка offscreen. Для частиц одинаковой формы используется offscreen-Canvas: частица рисуется один раз на скрытом Canvas, а затем копируется на основной через drawImage с прозрачностью. Это быстрее, чем каждый раз вызывать arc и fill.


5. Интеграция с таймлайном "Пирожков с нуля"
-----------------------------------------------

Система частиц привязана к таймлайну сцены:

- Сцена замешивания (0:00-3:00): Мука + пузырьки. Количество частиц нарастает от 0 до 150.
- Сцена духовки (6:00-9:00): Искры при открытии дверцы. Взрыв из 80 частиц за 2 секунды.
- Сцена подачи (12:00-14:00): Пар от пирожка. Постоянное генерирование 10-20 частиц в секунду.

Управление количеством частиц через таймлайн позволяет создавать динамику: от тихого начала к эффектному финалу. Это часть драматургии — физика служит сюжету.


Заключение
-----------

Система частиц — это мост между физикой и эстетикой. Правильно настроенная, она превращает статичную сцену в живую, дышащую картинку. В проекте "Пирожки с нуля" частицы не просто украшают — они рассказывают историю: мука летит, пар поднимается, искры сверкают. Освоив основы физики частиц, аниматор получает инструмент, который делает Canvas-мультик по-настоящему живым.
