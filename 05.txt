СИСТЕМА КАМЕР В АНИМАЦИИ: ВЫБОР РАКУРСА КАК ИНСТРУМЕНТ
========================================================

Введение
--------

Камера — это "глаз" зрителя. Там, куда она направлена, там и происходит действие. В классическом кино режиссёр выбирает ракурс не случайно: крупный план создаёт эмоциональную близость, общий план показывает контекст, средний —平衡 между деталями и окружением. В Canvas-анимации камера — это матрица преобразования контекста, и правильное её использование превращает информацию в историю. В проекте "Пирожки с нуля" система камер позволяет менять ракурс внутри одной сцены, создавая кинематографический эффект.


1. Три стандартных ракурса
--------------------------

Основа кинематографического языка — три базовых масштаба изображения:

Общий план (wide shot). Показывает всё пространство сцены целиком. Зритель видит персонажа, его окружение, обстановку. В "Пирожках с нуля" общий план используется в начале каждой сцены, чтобы зритель понял, где находится пекарь и что его окружает: рабочий стол, духовка, ингредиенты.

Средний план (medium shot). Фигура персонажа от пояса и выше. Окружение видно, но не доминирует. Это "рабочий" план для most сцен: зритель видит действия рук пекаря и его лицо одновременно.

Крупный план (close-up). Детали: лицо, руки, предмет. Создаёт эмоциональное напряжение или фокусирует внимание на важной детали. В "Пирожках с нуля" крупный план используется для показа теста в духовке, лица барашка, когда он пробует пирожок, и руки, формирующей тесто.

Соотношение этих планов в 15-минутном фильме:
- Общий план: 20-25% времени (начала сцен, финалы).
- Средний план: 50-60% времени (основное действие).
- Крупный план: 15-25% времени (эмоциональные акценты).


2. Зачем выбирать камеру в мультике
-------------------------------------

В отличие от живого кино, где камера физически перемещается, в Canvas-анимации камера — это виртуальная матрица трансформации. Выбор ракурса в мультике решает три задачи:

Направление внимания. Зритель смотрит на то, куда указывает камера. Если камера на крупном плане показывает руки, формирующие пирожок, зритель понимает: это ключевой момент рецепта.

Эмоциональное управление. Крупный план лица создаёт эмпатию. Общий план — дистанцию. Средний план — баланс. В "Пирожках с нуля" камера приближается к лицу барашка, когда он радуется удачной выпечке, и отдаляется, когда он сосредоточен на работе.

Информационная иерархия. Камера определяет, что важно прямо сейчас. Если на сцене есть пять ингредиентов и персонаж, камера выбирает, что показать крупно: лицо пекаря или тарелку с мукой.


3. Кинематографические приёмы на Canvas
-----------------------------------------

Помимо базовых планов, Canvas позволяет реализовать продвинутые приёмы:

Zoom (приближение/отдаление). Плавное изменение масштаба камеры. Реализуется через ctx.scale:

  function drawWithZoom(ctx, zoom, centerX, centerY) {
    ctx.save();
    ctx.translate(centerX, centerY);
    ctx.scale(zoom, zoom);
    ctx.translate(-centerX, -centerY);
    // рисуем сцену
    ctx.restore();
  }

В "Пирожках с нуля" zoom используется для перехода от общего плана к среднему: камера плавно приближается к столу пекаря, и зритель оказывается "в процессе".

Pan (панорамирование). Горизонтальное или вертикальное перемещение камеры. Реализуется через ctx.translate:

  function drawWithPan(ctx, offsetX, offsetY) {
    ctx.save();
    ctx.translate(offsetX, offsetY);
    // рисуем сцену
    ctx.restore();
  }

Pan используется для перемещения между рабочими зонами: от стола с тестом к духовке.

Rack focus (смена фокуса). В 2D-анимации имитируется через размытие: один план рисуется чётко, другой — с добавлением blur-эффекта (размытие через plusieurs вызовов drawImage с уменьшением разрешения).

  // Эффект размытия: рисуем мелко и увеличиваем
  ctx.drawImage(offscreen, 0, 0, width/4, height/4);
  ctx.drawImage(offscreen, 0, 0, width, height);

Rack focus в "Пирожках с нуля" используется для перехода от фона (стол, стены) к персонажу (барашек) — зрительский взгляд естественно перемещается на чёткий объект.


4. Связь ракурса с эмоцией сцены
----------------------------------

Каждый ракурс несёт эмоциональную нагрузку:

Общий план → безопасность, контекст, спокойствие. Зритель видит мир целиком и чувствует себя наблюдателей.

Средний план → вовлечённость, действие. Зритель становится соучастником.

Крупный план → напряжение, интимность, важность момента. Зритель оказывается "внутри" эмоции.

В проекте "Пирожки с нуля" эта связь используется осознанно:
- Начало сцены: общий план — "вот наша кухня, вот пекарь".
- Замешивание теста: средний план — "барашек работает, смотрите на его руки".
- Момент истины (пирожок из духовки): крупный план — "лицо пекаря выражает радость".
- Финал сцены: общий план — "пирожок готов, кухня спокойна".

Эта динамика — общее → частное → общее — создаёт ритм, подобный дыханию.


5. Пример: одна сцена — три разных восприятия
------------------------------------------------

Рассмотрим одну и ту же сцену — "барашек достаёт пирожок из духовки" — с тремя разными ракурсами:

Общий план: Видна вся кухня. Духовка справа, стол слева, барашек по центру. Зритель понимает пространственную организацию. Эмоция: спокойствие, ожидание.

Средний план: Барашек от пояса, духовка за его спиной. Зритель видит, как он тянет ручку дверцы. Эмоция: участие в действии, понимание процесса.

Крупный план: Только лицо барашка и его руки на ручке духовки. Зритель видит блеск в глазах и лёгкую дрожь пальцев. Эмоция: напряжение, радость, предвкушение.

Одно и то же действие, три разных эмоциональных переживания — всё благодаря выбору ракурса. В Canvas-анимации это решается одной строкой кода: изменением параметров масштаба и позиции контекста.


6. Техническая реализация камеры в "Пирожках с нуля"
------------------------------------------------------

Камера реализована как объект с методами:

  class Camera {
    constructor() {
      this.x = 0;
      this.y = 0;
      this.zoom = 1;
      this.targetZoom = 1;
      this.smoothing = 0.05;
    }

    update() {
      this.zoom += (this.targetZoom - this.zoom) * this.smoothing;
    }

    apply(ctx) {
      ctx.save();
      ctx.translate(this.x, this.y);
      ctx.scale(this.zoom, this.zoom);
    }

    restore(ctx) {
      ctx.restore();
    }

    setZoom(zoom) {
      this.targetZoom = zoom;
    }

    panTo(x, y) {
      this.x = x;
      this.y = y;
    }
  }

Плавное приближение достигается через smoothing: целевой масштаб отличается от текущего, и каждый кадр текущий приближается к целевому на 5%. Это создаёт естественное, "кинематографическое" движение камеры.


Заключение
-----------

Система камер — это не техническая необходимость, а художественный инструмент. В проекте "Пирожки с нуля" камера превращает последовательность кадров в историю с эмоциональной дугой. Правильный выбор ракурса направляет взгляд, создаёт напряжение и даёт дыхание. Canvas предоставляет всё необходимое для реализации кинематографических приёмов — остаётся только думать как режиссёр.
