ПРОЕКТИРОВАНИЕ UX ДЛЯ ОБРАЗОВАТЕЛЬНОГО МУЛЬТИКА
═════════════════════════════════════════════════

Введение
────────

UX-дизайн образовательного мультика — это баланс между развлечением и обучением. Зритель должен не просто смотреть, а понимать, запоминать, применять. Проект «Пирожки с нуля» — это интерактивный мультфильм, который учит готовить пирожки. Каждый элемент интерфейса продуман для максимального удобства и вовлечённости. Разберём, как проектировать UX для образовательного контента на Canvas.


Пользовательский путь: интро → просмотр → финал → replay
─────────────────────────────────────────────────────────

Путь пользователя (user journey) в проекте «Пирожки с нуля»:

Этап 1 — Интро (0-10 сек):
- Знакомство с персонажем и кухней
- Объяснение концепции: «мы будем готовить пирожки»
- Минимум интерфейса: только стартовая кнопка
- Mood: cheerful, тёплый, приглашающий

Этап 2 — Просмотр (основное время):
- Эпизоды: ПРОЛОГ → ПРОБУЖДЕНИЕ → СМЕШЕНИЕ → ФОРМОВКА → ВЫПЕЧКА
- Субтитры с пояснениями
- Прогресс-бар внизу
- Минимальный UI: не отвлекать от контента

Этап 3 — Финал (последние 10 сек):
- Пирожок готов! Эмоциональная развязка
- Появляются кнопки replay
- Прогресс-бар на 100%
- Mood: cheerful, радость результата

Этап 4 — Replay (опционально):
- Выбор пресета: closeup / wide / drama
- Перезапуск текущей сцены или всего мультика
- Возможность изучить детали
- Mood: зависит от выбранного пресета

Каждый этап чётко разграничен. Пользователь всегда знает, где он находится и что делать дальше.


Точки принятия решений: выбор камеры
────────────────────────────────────

В мультике есть две ключевые точки, где зритель принимает решение:

1. Выбор пресета в replay-режиме:
- Closeup → «Я хочу изучить детали процесса»
- Wide → «Я хочу увидеть атмосферу кухни»
- Drama → «Я хочу пережить эмоциональную арку»

2. Выбор скорости (будущее развитие):
- Normal → стандартная скорость
- Slow → для детального изучения
- Fast → для повторного просмотра

Каждое решение должно быть:
- Видимым: кнопки большие, читаемые
- Понятным: текст + иконка
- Обратимым: можно переключить в любой момент
- Безопасным: неправильного выбора не существует

В проекте «Пирожки с нуля» точки решений minimalistичны: три кнопки replay в финале. Не больше, не меньше. Каждая — осознанный выбор.


Минимальное количество кликов
─────────────────────────────

Принцип: чем меньше кликов, тем лучше. Для основного потока:

0 кликов: мультфильм запускается автоматически
1 клик: старт (если нужна начальная кнопка)
0 кликов: эпизоды сменяются автоматически
1 клик: выбор replay-режима

Итого: 1-2 клика за весь просмотр. Это идеально для образовательного контента: зритель не отвлекается на навигацию, а сосредоточен на содержании.

Каждый дополнительный клик — потерянный зритель. Если пользователю нужно нажать «далее» между каждым эпизодом, он устанет и закроет страницу. Автоматическое переключение с возможостью ручного контроля — оптимальный баланс.


Визуальная иерархия
───────────────────

Визуальная иерархия определяет, что зритель замечает первым:

Уровень 1 — Контент (приоритет максимум):
- Персонаж, его действия
- Еда, процесс готовки
- Субтитры с пояснениями

Уровень 2 — Прогресс (приоритет средний):
- Прогресс-бар
- Эпизодный заголовок
- Таймер

Уровень 3 — Управление (приоритет минимум):
- Кнопки replay (только в финале)
- Настройки звука (будущее)
- Меню (будущее)

Визуальная иерархия реализуется через:
- Размер: контент >> прогресс > управление
- Яркость: контент ярче, управление приглушено
- Позиция: контент по центру, управление по краям
- Анимация: контент движется, управление статично

В проекте «Пирожки с нуля» это выглядит так: основной canvas-контент занимает 90% экрана, прогресс-бар — тонкая полоса внизу, кнопки replay — компактный блок в финале.


Touch-friendly: кнопки достаточно большие
─────────────────────────────────────────

Для мобильных устройств:

Минимальный размер кнопки: 48x48 CSS пикселей (рекомендация Google Material Design)
Расстояние между кнопками: минимум 8px
Отступ от края экрана: минимум 16px

В проекте кнопки replay:

┌─────────┬──────────┬─────────┐
│ 96x48   │ 96x48    │ 96x48   │  ← размер каждой кнопки
│ closeup │  wide    │  drama  │
└─────────┴──────────┴─────────┘
     8px      8px       8px      ← расстояние между

Реализация:

const BUTTON_MIN_SIZE = 48;
const BUTTON_GAP = 8;
const BUTTON_PADDING = 16;

function drawReplayButtons(ctx) {
  const btnW = 96;
  const btnH = 48;
  const totalW = btnW * 3 + BUTTON_GAP * 2;
  const startX = (W - totalW) / 2;
  const y = H - btnH - BUTTON_PADDING;

  ['CLOSEUP', 'WIDE', 'DRAMA'].forEach((name, i) => {
    const x = startX + i * (btnW + BUTTON_GAP);
    drawButton(ctx, x, y, btnW, btnH, name);
  });
}


Мобильная адаптация
───────────────────

Адаптация для мобильных устройств:

Размер экрана:
- Desktop: 1920x1080 (полный Canvas)
- Tablet: 768x1024 (масштабирование)
- Mobile: 375x667 (масштабирование + crop)

Стратегия масштабирования:

function resizeCanvas() {
  const container = document.getElementById('canvas-container');
  const maxWidth = container.clientWidth;
  const maxHeight = container.clientHeight;

  // Сохраняем пропорции 16:9
  const targetRatio = 16 / 9;
  let width = maxWidth;
  let height = width / targetRatio;

  if (height > maxHeight) {
    height = maxHeight;
    width = height * targetRatio;
  }

  canvas.style.width = width + 'px';
  canvas.style.height = height + 'px';
}

Особенности мобильного UX:
- Прогресс-бар тоньше (4px вместо 6px)
- Кнопки replay крупнее (относительно экрана)
- Субтитры больше (минимум 14px)
- Параллакс упрощён (меньше слоёв)
- Frame rate: 30 FPS вместо 60 (экономия батареи)


Заключение
──────────

UX-дизайн образовательного мультика — это про уважение к зрителю. Проект «Пирожки с нуля» минимизирует количество кликов, максимизирует визуальную иерархию и адаптируется под любое устройство. Каждый элемент интерфейса продуман: от размера кнопок до тайминга эпизодных заголовков. Результат — мультфильм, который учит, не отвлекая на навигацию.
