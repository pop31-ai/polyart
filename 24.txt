ПАРАЛЛАКС И ГЛУБИНА В 2D-АНИМАЦИИ НА CANVAS
═════════════════════════════════════════════

Введение
────────

Двумерный Canvas — плоская поверхность. Но человеческий мозг привык воспринимать мир трёхмерным, и один из способов создать иллюзию глубины на плоском экране — параллакс. Это эффект, при котором объекты, расположенные ближе к зрителю, двигаются быстрее, чем удалённые. Проект «Пирожки с нуля» активно использует параллакс для создания ощущения объёмного пространства кухни.


Создание иллюзии глубины: передний план, средний, задний
────────────────────────────────────────────────────────

Принцип параллакса основан на физике восприятия:

- Передний план (foreground): движется быстро, крупные объекты, высокая детализация
- Средний план (midground): движется средне, основные объекты сцены
- Задний план (background): движется медленно или статичен, размытые детали

В проекте «Пирожки с нуля» это выглядит так:

Задний план (скорость × 0.2):
- Стена кухни
- Окно с видом на небо
- Полки с посудой

Средний план (скорость × 1.0):
- Рабочий стол
- Ингредиенты
- Руки персонажа

Передний план (скорость × 1.5):
- Пар от пирожков
- Летящие крошки
- Элементы декора на переднем плане

Каждый слой — это отдельный вызов.drawImage с собственным смещением:

function drawParallaxLayers(ctx, offsetX, offsetY) {
  // Задний план
  ctx.save();
  ctx.translate(offsetX * 0.2, offsetY * 0.2);
  drawBackground(ctx);
  ctx.restore();

  // Средний план
  ctx.save();
  ctx.translate(offsetX * 1.0, offsetY * 1.0);
  drawMidground(ctx);
  ctx.restore();

  // Передний план
  ctx.save();
  ctx.translate(offsetX * 1.5, offsetY * 1.5);
  drawForeground(ctx);
  ctx.restore();
}


Слои: фон → стол → предметы → персонаж
───────────────────────────────────────

Архитектура слоёв проекта строго иерархична:

Layer 0 — Фон (background):
- Фоновый градиент (mood-система)
- Стена, окно, небо за окном
- Статичен или движется минимально

Layer 1 — Среда (environment):
- Рабочий стол с текстурой дерева
- Полки, посуда, декор
- Лёгкое движение при плавании камеры

Layer 2 — Предметы (objects):
- Миска с тестом
- Сосуды с ингредиентами
- Стакан муки, масло
- Движение при взаимодействии персонажа

Layer 3 — Персонаж (character):
- Руки персонажа
- Основной фокус анимации
- Детализация мимики, движений

Layer 4 — Эффекты (effects):
- Пар, крошки, блики
- Передний план для глубины
- Максимальная скорость движения

Каждый слой рисуется отдельно с собственным transform:

const layers = [
  { speed: 0.1, draw: drawBackground },
  { speed: 0.4, draw: drawEnvironment },
  { speed: 0.8, draw: drawObjects },
  { speed: 1.0, draw: drawCharacter },
  { speed: 1.5, draw: drawEffects }
];

function renderFrame(ctx, cameraX, cameraY) {
  layers.forEach(layer => {
    ctx.save();
    ctx.translate(
      -cameraX * layer.speed,
      -cameraY * layer.speed
    );
    layer.draw(ctx);
    ctx.restore();
  });
}


Разная скорость движения слоёв
──────────────────────────────

Коэффициент скорости (speed factor) определяет, насколько сильно слой реагирует на движение камеры:

- Фон: 0.1 — почти статичен, создаёт ощущение далёкого пространства
- Среда: 0.4 — медленно движется, как за окном поезда
- Предметы: 0.8 — основное движение, привязано к камере
- Персонаж: 1.0 — полная привязка к камере (персонаж «в фокусе»)
- Эффекты: 1.5 — сверхбыстрое движение для глубины

Эти коэффициенты не случайны. Они следуют логическому правилу: чем дальше объект, тем меньше его воспринимаемое движение. Разница между 0.1 и 1.5 — в 15 раз, что создаёт ощутимую глубину даже при минимальном движении камеры.


Параллакс в сцене кухни: облака, окно, стол
────────────────────────────────────────────

В сцене кухни параллакс реализован максимально подробно:

Облака за окном (Layer 0, speed 0.05):
- Медленно дрейфуют справа налево
- Скорость: 2px за секунду
- Создают ощущение внешнего мира

Окно и рама (Layer 0.5, speed 0.15):
- Статичны, но смещаются при движении камеры
- Свет из окна — radial gradient, статичный

Стол (Layer 1, speed 0.5):
- Текстура дерева с деталями
- Лёгкое смещение при наклоне камеры
- Тени от предметов статичны

Предметы на столе (Layer 2, speed 0.8):
- Миска, ложка, ингредиенты
- Движение при подъёме камеры
- Взаимодействие с персонажем

Руки персонажа (Layer 3, speed 1.0):
- Полная привязка к камере
- Детализация: вены, текстура кожи, движение суставов

Пар от теста (Layer 4, speed 1.3):
- Поднимается вверх с ускорением
- Полупрозрачные эллипсы
- Максимально быстрое движение для глубины


Простая реализация через translate
───────────────────────────────────

Полная реализация параллакса — это цикл отрисовки слоёв:

function renderParallax(ctx, camera) {
  ctx.clearRect(0, 0, W, H);

  layers.forEach((layer, i) => {
    ctx.save();

    // Масштаб для глубины (дальние объекты меньше)
    const depthScale = 1 - (i / layers.length) * 0.1;
    ctx.translate(W/2, H/2);
    ctx.scale(depthScale, depthScale);
    ctx.translate(-W/2, -H/2);

    // Смещение параллакса
    const px = -camera.x * layer.speed;
    const py = -camera.y * layer.speed;
    ctx.translate(px, py);

    // Отрисовка слоя
    layer.draw(ctx);

    ctx.restore();
  });
}

translate — это основной инструмент параллакса. Никаких матриц, никаких сложных вычислений — просто смещение каждого слоя на разную величину. Элегантность решения в его простоте.


Заключение
──────────

Параллакс в проекте «Пирожки с нуля» — это не декоративный эффект, а функциональный инструмент создания пространства. Четыре-пять слоёв с разной скоростью движения превращают плоский Canvas в ощутимо объёмную кухню. Простая реализация через ctx.translate() не требует сложных библиотек, но даёт профессиональный результат, сопоставимый с полноценными 2D-движками.
