# Журнал проверок логической сходимости

Проверки модулей polyart: документация ↔ код ↔ UML, грамматика ↔ парсер,
конвертер ↔ формат, мета-язык ↔ примеры.

Формат записи: `[ID] статус — что проверяли → результат (подробности)`.

## Замечания по методу

- `ЛОГИЧЕСКАЯ СХОДИМОСТЬ` = документация, грамматика, парсер, интерпретатор,
  конвертер и UML должны описывать одно и то же поведение.
- Статусы: НАЙДЕНО → ИСПРАВЛЕНО → ПРОВЕРЕНО.
