# PolyArt Статья 01: Полиномиальная живопись в инди-играх

## Проблема

Инди-разработчикам нужны атмосферные фоны и арты, но нанять
художника на каждую сцену дорого. Стоковые текстуры повторяются
и «не живут».

## Решение: полиарт + двойник кисти

`polyart_brush_twin.py` генерирует мазки масляной кисти по
полиномиальным кривым. Каждый кадр уникален, потому что:

- щетины ложатся со случайной фактурой (seed);
- давление и поворот кисти меняют ширину следа;
- импосто, лессировка и wet-on-wet дают глубину, как у настоящей
  картины.

## Сценарий использования

```python
from polyart_brush_twin import OilBrushTwin, impasto, wet_on_wet

# фон для экрана меню
sky = np.linspace(-5, 5, 150)
wet_on_wet(ax, sky, 3 - sky*0.1, c1="#2a4a8a", c2="#c8a040", width=2.0)

# гора на заднем плане
ridge = np.array([-5, -3, -1.5, 0.5, 2.5, 5])
ridge_y = np.array([-2, 0.5, -0.5, 1.5, 0.0, -2])
impasto(ax, ridge, ridge_y, color="#3a4a5a", thickness=0.4, width=1.5)

# дерево на переднем плане
brush = OilBrushTwin(size="liner", paint="#2a1a0a", load=0.9)
brush.stroke(ax, [0, 0], [-2, 1], pressure=0.8)
```

## Почему это выгодно

- **Скорость**: одна функция — одна деталь сцены.
- **Уникальность**: меняя seed, получаем бесконечные вариации.
- **Легковесность**: чистые numpy-массивы, легко встроить в пайплайн.
- **Стиль**: масляная фактура выделяет игру среди «пластиковых»
  градиентов.

## Итог

Полиарт подходит для:
- фонов экранов меню и лоудинга;
- концепт-артов и превью;
- карт и локаций в стиле «живописной сказки»;
- генерации арта по числовым параметрам (сид, настроение).
