# PolyArt Статья 03: Открытки и сувениры в технике масляной живописи

## Проблема

Печатная продукция (открытки, постеры, кружки, стикеры) требует
уникальных изображений. Стоки дороги, а генераторы дают
«цифровую пластмассу».

## Решение

Масляная фактура полиарта выглядит «живой» даже в печати: бороздки
щетин и рельеф импосто считываются как настоящая картина малого
формата.

## Открытка «Закат над морем»

```python
from polyart_brush_twin import impasto, wet_on_wet, OilBrushTwin

# небо
t = np.linspace(-5, 5, 160)
wet_on_wet(ax, t, 3 - t*0.1, c1="#f0c020", c2="#d94a2a", width=2.5, alpha=0.85)

# солнце импосто
sun = np.linspace(0, 2*np.pi, 80)
impasto(ax, 0.5*np.cos(sun), 1.5 + 0.5*np.sin(sun),
        color="#ffe060", thickness=0.3, width=1.0, alpha=0.95)

# море
wet_on_wet(ax, t, -1 - t*0.02, c1="#2a4a8a", c2="#4a90d9", width=2.0, alpha=0.7)
```

## Идеи для сувениров

- новогодние открытки с елью из отпечатков кисти (dab);
- постеры «северное сияние» веерной кистью (fan_out);
- этикетки и упаковка с масляными натюрмортами;
- раскраски-образцы для мастер-классов.
