# PolyArt Урок 04: Wet-on-wet — смешивание на холсте

## Цель

Научиться приёму «алла прима» (wet-on-wet): смешивание краски прямо
на сыром холсте, без высыхания слоёв.

## Теория

В технике wet-on-wet цвета вводятся один в другой по длине мазка.
На сыром холсте они мягко растекаются, давая плавные переходы.
Двойник кисти моделирует это функцией `wet_on_wet`.

## Основной приём

```python
import numpy as np
from polyart_brush_twin import wet_on_wet

t = np.linspace(-4, 4, 120)
x = t
y = 0.6 * np.sin(1.5 * t)

wet_on_wet(ax, x, y, c1="#d94a6e", c2="#4a90d9", width=1.2, alpha=0.8)
```

Цвет плавно меняется от красного к синему вдоль мазка.

## Параметры

| Параметр | Описание                            |
|----------|-------------------------------------|
| `c1`     | начальный цвет                      |
| `c2`     | конечный цвет                       |
| `width`  | ширина мазка                        |
| `steps`  | число сегментов смешивания          |
| `alpha`  | непрозрачность                      |

## Небо-градиент

```python
x2 = np.linspace(-5, 5, 150)
for i in range(6):
    yy = 4 - i * 1.4
    wet_on_wet(ax, x2, np.full_like(x2, yy),
               c1=["#1a2a5a", "#2a4a8a", "#3a6a9a",
                    "#c8a040", "#e08040", "#8a2a2a"][i],
               c2=["#2a4a8a", "#3a6a9a", "#c8a040",
                    "#e08040", "#8a2a2a", "#4a1010"][i],
               width=1.3, alpha=0.75)
```

## Вода с отражением

```python
wx = np.linspace(-5, 5, 150)
wy = -3 + 0.3 * np.sin(wx * 2)
wet_on_wet(ax, wx, wy, c1="#4a90d9", c2="#d9e8f0", width=1.0, alpha=0.6)
wet_on_wet(ax, wx, wy - 0.4, c1="#d9e8f0", c2="#4a90d9", width=1.0, alpha=0.5)
```

## Проверка

- Переход между цветами плавный, без резкой границы.
- Небо и море визуально связаны (общие цвета).
- Мазок имеет «живые» края от смягчающих проходов.
