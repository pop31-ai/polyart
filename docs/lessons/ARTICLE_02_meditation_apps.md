# PolyArt Статья 02: Фоны для обучающих и медитативных приложений

## Проблема

Приложениям для релаксации, медитации и обучения нужны спокойные,
«живые» фоны. Идеально ровные градиенты кажутся стерильными,
а фото — отвлекают.

## Почему масляный фон

Мазки масляной кисти с мягкими переходами (wet-on-wet) и лёгким
рельефом (импосто) создают тёплое, рукотворное ощущение. Это
снижает тревожность и удерживает внимание.

## Палитра спокойствия

```python
from polyart_brush_twin import glaze, wet_on_wet

# мягкое вечернее небо
t = np.linspace(-5, 5, 160)
wet_on_wet(ax, t, 2.5 - t*0.05,
           c1="#d9c8a8", c2="#a89070", width=2.2, alpha=0.6)

# облака лессировкой
glaze(ax, t + np.sin(t*0.8), 1.8 - t*0.05,
      color="#e8dcc8", alpha=0.2, width=1.8)
```

## Плавная смена состояний

Параметры `c1`, `c2`, `alpha`, `thickness` можно анимировать:
с течением дня небо медленно переходит из утренних тонов в закатные.
Кисть каждый раз даёт слегка новую фактуру, поэтому фон «дышит»,
не отвлекая.

## Для обучения

- обложки уроков в мягких тонах;
- фоновые панели тестов и квизов;
- заставки между разделами курса.

## Итог

Масляная полиарт-живопись — готовый визуальный язык для спокойных
продуктов. Один и тот же модуль даёт бесконечные вариации одного
настроения.
