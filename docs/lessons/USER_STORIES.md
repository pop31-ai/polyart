# PolyArt Пользовательские истории

Истории реальных сценариев работы с цифровым двойником кисти.
Каждая история — короткий сценарий «кто-что-зачем».

---

## История 1. Марина, инди-разработчик

**Роль:** разработчик игры «Северный сад».

**Потребность:** фон экрана загрузки, который не повторяется.

**Что сделала:**

```python
from polyart_brush_twin import OilBrushTwin, wet_on_wet

t = np.linspace(-5, 5, 160)
wet_on_wet(ax, t, 2 - t*0.05, c1="#2a4a8a", c2="#c8a040")
b = OilBrushTwin(size="fan", paint="#e8e0c8")
for a in range(12):
    b.fan_out(ax, np.cos(a), np.sin(a), radius=0.4, spread_angle=0.8, n_rays=5)
```

**Результат:** за пару минут получила живой масляный фон.
Каждый запуск — новый seed, новая картина.

**Цитата:** «Думала, придётся рисовать вручную. Оказалось — десять
строк кода и уникальный арт.»

**Что сделала:**

