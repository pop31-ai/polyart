# PolyArt Урок 06: Отпечатки и веерная кисть

## Цель

Научиться использовать отпечатки щетин (`dab`) и веерную кисть
(`fan_out`) — для цветов, листвы, сияния и волос.

## Отпечатки кисти — тычок

```python
from polyart_brush_twin import OilBrushTwin

brush = OilBrushTwin(size="round", paint="#5a2a6a", load=0.9, seed=1)

# цветок
import numpy as np
for a in np.linspace(0, 2*np.pi, 12, endpoint=False):
    px = np.cos(a) * 0.4
    py = np.sin(a) * 0.4
    brush.dab(ax, px, py, radius=0.2, pressure=0.9)
brush.dab(ax, 0, 0, radius=0.22, pressure=1.0)
```

Каждый `dab` — отпечаток пучка щетин, выглядит как соцветие сирени
или гортензии.

## Веерная кисть

```python
fan = OilBrushTwin(size="fan", paint="#c8a020", load=0.8, seed=2)

# сияние солнца
fan.fan_out(ax, 0, 0, radius=1.5, spread_angle=2*np.pi, n_rays=12)
```

`fan_out` рисует расходящиеся лучи щетин. Используется для:
- солнца и лучей света
- травы и волос
- искр и фейерверков

## Трава веером

```python
for gx in np.linspace(-4, 4, 9):
    fan.fan_out(ax, gx, -3.5, radius=0.7,
                spread_angle=np.pi/2, n_rays=5)
```

## Параметры `fan_out`

| Параметр       | Описание                    |
|----------------|-----------------------------|
| `cx, cy`       | точка основания веера       |
| `radius`       | длина лучей                 |
| `spread_angle` | угол раскрытия (радианы)    |
| `n_rays`       | число щетин-лучей           |

## Задание

Нарисуйте ветку цветущей сирени: центральная ветка (liner), 6-8
соцветий из отпечатков `dab` (сиреневый/белый), листья — веером
зелёной кисти.

## Проверка

- Соцветия состоят из множества отдельных отпечатков.
- Лучи веера расходятся из одной точки.
- Общая композиция напоминает живое растение.
