# PolyArt Урок 02: Импосто — густая краска

## Цель

Научиться наносить густой рельефный слой краски (импосто) — приём,
которым работали Ван Гог и Моне.

## Теория

Импосто — это толстый слой краски, который выступает над холстом.
Цифровой двойник моделирует это тремя слоями:

1. нижняя тёмная тень (рельеф),
2. основной густой мазок,
3. светлые бороздки щетин и бликовая кромка.

## Функция `impasto`

```python
import numpy as np
from polyart_brush_twin import impasto

x = np.linspace(-4, 4, 120)
y = 0.8 * np.sin(2 * x)

impasto(ax, x, y, color="#8a2a2a", thickness=0.35, width=1.2, alpha=0.95)
```

Параметры:

| Параметр     | Описание                              |
|--------------|---------------------------------------|
| `color`      | цвет краски (#hex)                    |
| `thickness`  | высота рельефа 0..1 (больше — гуще)   |
| `width`      | ширина мазка                          |
| `alpha`      | непрозрачность                        |

## Упражнение: волны импосто

```python
for i in range(5):
    yy = i * 1.6 - 3.5
    phase = i * 0.8
    impasto(ax, x, yy + 0.4 * np.sin(3 * x + phase),
            color=["#2a4a7a", "#8a2a2a", "#2a7a3a", "#c8a020", "#7a2a6a"][i],
            thickness=0.25 + 0.05 * i, width=1.1, alpha=0.9)
```

## Свет и тень

Импосто автоматически добавляет тёмную кромку снизу и светлую — сверху.
Это создаёт иллюзию объёма без дополнительных настроек.

## Задание

Нарисуйте солнце в технике импосто: круг + расходящиеся лучи-мазки.
Используйте `impasto` для каждого луча с жёлтым цветом `#f0c020`.

## Проверка

- Края мазка «рваные», не идеально ровные.
- Внутри мазка видны бороздки от щетин.
- Есть тёмная нижняя и светлая верхняя кромки.
