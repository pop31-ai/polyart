# PolyArt Статья 04: Портреты и персонажи масляным мазком

## Проблема

Художникам и иллюстраторам нужно быстро получать концепты
персонажей в масляной манере, не тратя часы на фактуру.

## Подход

Лицо строится из полиномиальных кривых (`polyart_curves.py`),
а фактура наносится двойником кисти. Кривые дают анатомию,
кисть — жизнь.

## Схема

```python
from polyart_curves import SkeletalCurves
from polyart_brush_twin import OilBrushTwin, impasto

# череп как каркас
SkeletalCurves.skull(ax, 0, 0, s=2.0, c="#e8dcc8", lw=0.5, al=0.4)

# объём импосто
brush = OilBrushTwin(size="flat", paint="#c8a888", load=0.8)
brush.stroke(ax, np.linspace(-1, 1, 80), -0.2 + 0.1*np.sin(np.linspace(0, 6, 80)),
             pressure=0.5, lw_mult=1.5)
```

## Техники для портрета

- **Тени на лице** — лессировка сине-серым по краям.
- **Скулы и лоб** — импосто светлым тёплым тоном.
- **Волосы** — веерная кисть и сухая кисть (длинные пряди).
- **Глаза** — liner, тонкие мазки + отпечаток блика.

## Упражнение: абстрактный портрет

1. `SkeletalCurves.skull` — каркас.
2. 3-4 слоя лессировки разными тонами кожи.
3. Волосы веером по контуру головы.
4. Блики импосто на лбу и носу.

## Итог

Полиарт позволяет собирать выразительные «масляные» персонажи,
комбинируя библиотеку кривых и двойник кисти. Каждый портрет
уникален за счёт seed.
