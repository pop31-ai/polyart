# PolyArt Статья 05: Анимация и движущиеся фоны

## Проблема

Статичные фоны выглядят мёртвыми. Нужны фоны, которые живут,
но без тяжёлых видеофайлов.

## Решение: генерация кадров полиартом

Каждый кадр — отдельная сцена с плавно меняющимися параметрами.
Вместо хранения сотен картинок храним формулу (кривые + параметры
кисти), а кадры генерируем на лету.

## Пример: «дышащее» небо

```python
import numpy as np
from polyart_painter import PainterCanvas

t = np.linspace(-6, 6, 160)
for frame in range(20):
    k = frame / 19
    c = PainterCanvas(xlim=(-6, 6), ylim=(-6, 6), background="#1a2a3a")
    c.wet_on_wet(t, 3 - t*0.05,
                 c1=mix("#2a4a8a", "#3a6a9a", k),
                 c2=mix("#c8a040", "#8a6a3a", k),
                 width=2.4, alpha=0.7)
    c.render(f"frames/breath_{frame:02d}.png", dpi=90)
```

## Плюсы подхода

- **Маленький размер**: код вместо гигабайт видео.
- **Бесконечность**: параметры времени не ограничены кадрами.
- **Интерактив**: пользователь влияет на параметры в реальном времени.

## Для чего годится

- заставки и лоудинги в играх;
- живые фоны меню;
- демо-экраны и скринсейверы;
- генеративный арт-модуль в веб-приложении.

## Итог

Полиарт-живопись — это не статичная картинка, а живая формула.
Анимация — просто рендер формулы в разные моменты времени.
