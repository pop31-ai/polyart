# PolyArt Урок 03: Лессировка — свет и глубина

## Цель

Научиться использовать лессировку (глазурь) — полупрозрачные тонкие слои
краски, которые накладываются поверх подсохшего нижнего слоя.

## Теория

Старые мастера (Тициан, Рембрандт) клали до 20 тонких прозрачных слоёв,
чтобы получить глубину света. Цифровой двойник повторяет приём функцией
`glaze`:

```python
from polyart_brush_twin import glaze

x = np.linspace(-4, 4, 120)
y = np.zeros_like(x)

# первый подмалёвок (плотный)
ax.plot(x, y, color="#8a6a3a", linewidth=2.0)

# три лессировочных слоя
glaze(ax, x, y, color="#c8a040", alpha=0.25)
glaze(ax, x, y, color="#d94a6e", alpha=0.18)
glaze(ax, x, y, color="#4a90d9", alpha=0.15)
```

Каждый слой полупрозрачен, поэтому краски смешиваются оптически —
не на палитре, а в глазу зрителя.

## Лессировка неба

```python
t = np.linspace(0, 1, 100)
sky_x = t * 10 - 5
sky_y = 4.0 - t * 3.0

glaze(ax, sky_x, sky_y, color="#b0a888", alpha=0.2, width=2.5)
glaze(ax, sky_x, sky_y + 0.3, color="#c8b090", alpha=0.15, width=2.5)
glaze(ax, sky_x, sky_y - 0.3, color="#a09070", alpha=0.18, width=2.5)
```

## Параметры

| Параметр | Описание                         |
|----------|----------------------------------|
| `alpha`  | прозрачность слоя (0.1 — едва видно, 0.5 — плотно) |
| `width`  | ширина мазка                     |
| `wobble` | сила дрожания кисти (фактура)    |

## Задание

Нарисуйте закат: три полосы (жёлтая, оранжевая, красная) плотным
импосто, а поверх — две лессировочных полосы синего и фиолетового.
Обратите внимание, как светлеет/темнеет нижний слой.

## Проверка

- Нижний слой просвечивает сквозь верхние.
- Многослойные участки выглядят глубже по цвету.
- Края слоёв мягкие, без резких границ.
