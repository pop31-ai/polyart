# PolyArt Архитектура: цифровой двойник кисти

## Обзор

Подсистема масляной живописи состоит из трёх модулей:

```
polyart_brush_twin.py   — ядро: двойник кисти и техники
polyart_painter.py      — интеграция с Canvas API (PainterCanvas)
docs/lessons/           — обучающие материалы
```

## Модуль 1: polyart_brush_twin.py (ядро)

### Класс OilBrushTwin

Цифровой двойник физической кисти. Хранит состояние:

| Поле | Тип | Описание |
|------|-----|----------|
| `size` | str | тип кисти: round/flat/filbert/fan/liner |
| `bristles` | int | число щетин |
| `taper` | float | сходимость щетин к кончику |
| `spread` | float | раскрытие пучка |
| `paint` | hex | цвет краски |
| `load` | float 0..1 | загрузка краски |
| `oiliness` | float | маслянистость |
| `pressure` | float | давление |
| `angle` | float | поворот кисти |
| `_spent` | float | израсходованная краска |

### Методы

| Метод | Назначение |
|-------|------------|
| `stroke()` | мазок с учётом щетин, давления, поворота, истощения |
| `dab()` | отпечаток пучка щетин |
| `fan_out()` | веер щетин |
| `reset_paint()` | перезарядка кисти |

### Физическая модель

- **Щетины**: смещения перпендикулярно кривой, зависят от давления.
- **Давление**: ширина мазка `0.6 + 0.8*p`.
- **Поворот**: эффективная ширина `0.55 + 0.45*|cos(angle)|`.
- **Истощение**: остаток краски `load * (1 - spent)`; к концу мазка
  след бледнеет и сужается.
- **Сухая кисть**: при `dry_brush=True` щетины оставляют прерывистые
  следы с вероятностью, зависящей от расхода.

### Модульные функции (техники)

| Функция | Моделирует |
|---------|------------|
| `impasto()` | густой слой: тень снизу, основной мазок, бороздки, блик |
| `glaze()` | полупрозрачный слой поверх подсохшего |
| `wet_on_wet()` | смешивание двух цветов по длине мазка |
| `dry_brush()` | прерывистые процарапывания |
| `mix()`, `shade()`, `hex_to_rgb()` | цветовые утилиты |

## Модуль 2: polyart_painter.py (интеграция)

`PainterCanvas(Canvas)` наследует полиарт-API и добавляет живопись.

### Паттерн «регистрация мазков»

Мазки не рисуются сразу, а записываются в `self._paint_strokes`
списком кортежей `(вид, кисть, args, kwargs)`. При `render()`
они применяются после объектов Canvas, поверх них:

```
слои Canvas -> формулы -> масляные мазки -> (опционально) круглая маска
```

### Преимущества паттерна

- Сохраняется порядок z-order: объекты под мазками.
- Можно переиспользовать холст и менять мазки до рендера.
- `.save()`/.load() работают как у базового Canvas.

### Класс PaintTemplates

Фабрика готовых сцен: `sunset_sea`, `autumn_forest`, `winter_sunset`.

## Данные

### Зависимости

- `numpy>=1.20`
- `matplotlib>=3.4`
- (опционально) `PIL` для склейки GIF

### Вход

Параметры: координаты кривых `(x, y)`, цвета `#hex`, параметры кисти.

### Выход

- `.polyart` — JSON со структурой Canvas + зарегистрированные мазки.
- `.png`/`.svg`/`.pdf` — через matplotlib.

## Решения и компромиссы

| Решение | Причина |
|---------|---------|
| Рисовать напрямую в matplotlib | совместимость с полиарт-API |
| Мазки регистрировать, а не рисовать сразу | сохранение z-order и сериализация |
| Отдельный Random с seed | воспроизводимость фактуры |
| Цвета в #hex | единый формат полиарт-API |

## Расширение

Чтобы добавить новую технику:

1. Реализуйте функцию в `polyart_brush_twin.py`.
2. Добавьте метод-обёртку в `PainterCanvas`.
3. Зарегистрируйте обработку в `_apply_paint()`.
4. Добавьте урок и кейс в `docs/lessons/`.
