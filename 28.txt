КУЛИНАРНАЯ ФИЗИКА: MAILLARD REACTION ВИЗУАЛЬНО
═════════════════════════════════════════════════

Введение
────────

Maillard reaction (реакция Майяра) — это химическая реакция между аминокислотами и还原糖 при температуре 140-165°C. Именно она responsible за коричневый цвет жареного мяса, хрустящую корочку хлеба и золотистый оттенок пирожков. В контексте анимации это не просто научный факт — это мощный инструмент визуального повествования. Проект «Пирожки с нуля» использует Maillard reaction как основу для анимации трансформации еды.


Что такое Maillard reaction: сахар + аминокислоты → коричневый цвет
──────────────────────────────────────────────────────────────────

Простое объяснение: когда белки и сахара нагреваются вместе, они образуют сотни различных соединений, включая меланоидины — пигменты, responsible за коричневый цвет.

В кулинарии это работает так:

- Мясо: белки + сахар → коричневая корочка
- Хлеб: глютен + сахар → золотистая корочка
- Пирожки: тесто + сахар → golden brown
- Лук: клеточный сахар + аминокислоты → карамельный цвет

Визуально Maillard reaction — это плавный переход от светлого (сырого) к коричневому (готовому). Этот переход — основа анимации готовки в проекте.


Визуализация: плавный переход цвета
────────────────────────────────────

Анимация Maillard reaction в Canvas — это интерполяция цвета от сырого к готовому:

Этап 1 — Сырой (0-20% времени):
- Цвет: #F5E6C8 (светлый, «сырой»)
- Текстура: гладкая, без дефектов
- Запах: «сырой» (визуально: нет пара)

Этап 2 — Начало (20-40%):
- Цвет: #E8D5A8 → #D4B87A
- Появляются первые «коричневые точки»
- Мелкие пузырьки на поверхности

Этап 3 — Активная фаза (40-70%):
- Цвет: #D4B87A → #DBB87A
- Усиление текстуры: поры, трещинки
- Появляется пар
- Поверхность становится «матовой»

Этап 4 — Готово (70-100%):
- Цвет: #DBB87A → #C9A05C
- Полная текстура: поры, трещины, неровности
- Пар активен
- Блик на жирной поверхности

function maillardColor(progress) {
  if (progress < 0.2) return lerpColor('#F5E6C8', '#E8D5A8', progress / 0.2);
  if (progress < 0.4) return lerpColor('#E8D5A8', '#D4B87A', (progress - 0.2) / 0.2);
  if (progress < 0.7) return lerpColor('#D4B87A', '#DBB87A', (progress - 0.4) / 0.3);
  return lerpColor('#DBB87A', '#C9A05C', (progress - 0.7) / 0.3);
}


Применение: лук, фарш, пирожки
──────────────────────────────

Maillard reaction визуально различается для разных продуктов:

Лук:
- Начало: прозрачный белый
- Середина: золотистый
- Конец: карамельный (#8B4513)
- Особенность: плавный, равномерный переход

Фарш:
- Начало: розовый (#FFB6C1)
- Середина: коричневый (#A0522D)
- Конец: тёмно-коричневый (#654321)
- Особенность: неравномерный, «пятнистый» переход

Пирожки:
- Начало: белый (#FFF8DC)
- Середина: золотистый (#DBB87A)
- Конец: коричневый (#C9A05C)
- Особенность: градиент от центра к краям

Каждый продукт требует自己的 цветовую кривую. В проекте «Пирожки с нуля» основной фокус на пирожках, но система расширена для поддержки других продуктов.


Анимация: rgb-interpolation
───────────────────────────

Основа анимации — интерполяция по каждому каналу RGB:

function lerpColor(color1, color2, t) {
  const r1 = parseInt(color1.slice(1,3), 16);
  const g1 = parseInt(color1.slice(3,5), 16);
  const b1 = parseInt(color1.slice(5,7), 16);
  const r2 = parseInt(color2.slice(1,3), 16);
  const g2 = parseInt(color2.slice(3,5), 16);
  const b2 = parseInt(color2.slice(5,7), 16);

  const r = Math.round(r1 + (r2 - r1) * t);
  const g = Math.round(g1 + (g2 - g1) * t);
  const b = Math.round(b1 + (b2 - b1) * t);

  return `rgb(${r},${g},${b})`;
}

Но простая интерполяция даёт линейный переход, который выглядит «плоско». Для более естественного эффекта используется кривая:

function maillardEase(t) {
  // S-образная кривая: медленно → быстро → медленно
  return t < 0.5
    ? 2 * t * t
    : 1 - Math.pow(-2 * t + 2, 2) / 2;
}

Эта кривая имитирует реальную физику: в начале реакция медленная (нагрев), потом быстрая (активная фаза), потом снова медленная (подготовка к завершению).


Связь цвета с процессом готовки
───────────────────────────────

Цвет — это индикатор процесса. В проекте «Пирожки с нуля» цвет пирожка напрямую связан с его «состоянием»:

progress 0%: Сырой тесто. Светлый, гладкий. Начало пути.
progress 25%: Начало нагрева. Первые признаки изменения.
progress 50%: Активная фаза. Золотистый цвет, появляется текстура.
progress 75%: Почти готово. Насыщенный golden brown, пар.
progress 100%: Готово. Идеальный цвет, полная текстура.

Эту связь можно усилить через «индикатор готовки»:

function drawCookingIndicator(ctx, progress) {
  const color = maillardColor(progress);
  ctx.fillStyle = color;
  ctx.fillRect(W - 30, H/2 - 50, 20, 100);
  ctx.fillStyle = '#fff';
  ctx.font = '12px sans-serif';
  ctx.textAlign = 'center';
  ctx.fillText(Math.round(progress * 100) + '%', W - 20, H/2 + 70);
}

Зритель видит не просто меняющийся цвет, а процесс трансформации. Это ключевой narrative device в мультике «Пирожки с нуля».


Заключение
──────────

Maillard reaction — это не просто кулинарный термин, а полноценный инструмент анимации. Проект «Пирожки с нуля» превращает химическую реакцию в визуальное повествование: плавный переход цвета, изменение текстуры, появление пара. Каждый этап анимации соответствует реальному процессу готовки, создавая образовательный и эстетический эффект одновременно. Секрет — в точности: правильные цвета, правильная кривая, правильная текстура.
