ЗВУКОВОЙ ДИЗАЙН ДЛЯ CANVAS-МУЛЬТИКОВ (КОНЦЕПЦИЯ)
===================================================

ВВЕДЕНИЕ
--------

Звук — невидимый половина мультфильма. Без него персонаж молча месит тесто, пар шипит беззвучно, таймер не тикает. Canvas рисует, но не воспроизводит звук — это ограничение платформы. Однако звуковой дизайн возможен и на вебе: через Web Audio API, через элемент <audio> и через субтитры как визуальную замену. В «Пирожках с нуля» мы исследуем все три подхода и находим баланс между «есть звук» и «нет звука».

WEB AUDIO API: ГЕНЕРАЦИЯ ТОНОВ И ШУМОВ
----------------------------------------

Web Audio API — это низкоуровневый интерфейс для работы со звуком в браузере. Он позволяет генерировать звуки программно: без загрузки аудиофайлов, без серверов, без задержек.

Основные компоненты:

Oscillator — генератор тонов. Типы волн: sine (чистый тон), square ( «8-битный» ), sawtooth (резкий), triangle (мягкий). Частота: от 20 до 20000 Гц. Пример: oscillator.type = 'sine', oscillator.frequency.value = 440 (нота ля).

Gain — регулятор громкости. gain.value от 0 (тишина) до 1 (максимум). Используется для fade-in/fade-out и плавных переходов.

Filter — эквалайzer. Low-pass filter убирает высокие частоты ( «мuffled» звук), high-pass — низкие ( «тонкий» звук).

Для «Пирожков с нуля» мы можем генерировать:

Тиканье таймера — короткий синусоидальный тон (440 Гц, 0.05 секунды, gain 0.3). Повторяется каждую секунду. Звук механических часов.

Шипение масла — white noise через AudioBuffer с random values, пропущенный через low-pass filter (частота 2000 Гц). Длительность: непрерывный, пока идёт жарка.

Хлоп (рукоплескание) — два импульса: короткий тон (800 Гц, 0.02 сек) + noise burst (0.01 сек). Имитирует хлопок ладоней.

BGM: ФОНОВАЯ МУЗЫКА ЧЕРЕЗ <AUDIO>
-------------------------------------

Web Audio API хорош для звуковых эффектов (SFX), но не для музыки. Длинные аудиофайлы (минуты) лучше воспроизводить через элемент <audio>:

<audio id="bgm" loop>
  <source src="music/ost.mp3" type="audio/mpeg">
</audio>

Преимущества:
- Браузер кэширует файл ( повторные воспроизведения быстрее).
- Поддержка сжатия (MP3, OGG, AAC).
- Встроенные события: canplaythrough, ended, timeupdate.

Управление через JavaScript:
- bgm.play() / bgm.pause().
- bgm.volume = 0.3 (тихий фон).
- bgm.currentTime = 0 (перемотка).

Для «Пирожков с нуля» BGM — это спокойная фортепианная мелодия (не отвлекающая, ритмичная, ~80 BPM). Мелодия меняется с муд-системой: cheerful — мажорный ключ, dramatic — минорный, calm — пентатоника, romantic — струнные.

SFX: ТИКАНЬЕ, ШИПЕНИЕ, ХЛОП
-------------------------------

Звуковые эффекты в «Пирожках с нуля» — не просто украшение. Они выполняют функции:

Тиканье — сигнал того, что время идёт. Зритель привыкает к ритму и подсознательно отслеживает прогресс. Тиканье ускоряется ×2 и ×60 вместе с таймером — слуховой сигнал ускорения.

Шипение — сигнал жара. Когда пирожки в духовке, шипение告诉зрителю: «Они готовятся! Это горячий процесс!» Громкость шипения привязана к progress: чем ближе к готовности, тем тише (масло выгорает).

Хлоп — момент разреза. Когда нож входит в тесто, короткий хлоп подчёркивает действие. Это акцент, как удар барабана в музыке — обозначает кульминацию.

SFX генерируются через Web Audio API и воспроизводятся одноразово (без loop). Каждый эффект — это短时间内создание oscillator + gain + filter, воспроизведение и остановка.

СИНТЕЗИРОВАННЫЕ ЗВУКИ: OSCILLATOR + GAIN
------------------------------------------

Синтезированные звуки — это звуки, созданные математически, без записи с микрофона. Преимущество: они весят 0 байт (генерируются на лету) и идеально подходят для минималистичных Canvas-мультиков.

Пример синтеза «пузырька»:
1. Oscillator: frequency 600 Гц, type sine.
2. Gain: плавное уменьшение от 0.3 до 0 за 0.2 секунды.
3. Frequency sweep: от 600 до 200 Гц за 0.2 секунды.
4. Результат: «плюх» — короткий тон, понижающийся по частоте.

Пример синтеза «venting» (выпуск воздуха из теста):
1. White noise (random values в AudioBuffer).
2. Low-pass filter: частота от 5000 до 1000 Гц за 0.5 секунды.
3. Gain: от 0.2 до 0 за 0.5 секунды.
4. Результат: «пшш» — шипение с затуханием.

Каждый синтезированный звук — 5-10 строк кода. Но вместе они создают звуковую палитру, которая рассказывает историю.

ОГРАНИЧЕНИЯ: БЕЗ АУДИО = ВИЗУАЛЬНЫЕ ПОДСКАЗКИ
------------------------------------------------

Не все звуки работают на всех устройствах. iOS блокирует автовоспроизведение до первого взаимодействия пользователя. Android может быть без звука. Десктоп — пользователь мог отключить звук.

Поэтому каждый звуковой сигнал имеет визуальную замену:

Тиканье → мигающая точка рядом с таймером (альтернативный визуальный ритм).
Шипение → частицы-искры + пульсация glow горелки.
Хлоп → вспышка яркого цвета на линии разреза.
BGM → отсутствует (нет визуальной замены для музыки).

Принцип: звук усиливает визуал, но не заменяет его. Мультфильм должен работать и без звука.

СУБТИТРЫ КАК ЗАМЕНА
----------------------

Субтитры в «Пирожках с нуля» — не перевод диалогов (персонаж молчит). Это звуковые подсказки:

[тика́ние таймера]
[шипение масла]
[хлопок ладоней]
[звуки духовки]

Субтитры появляются в нижней части экрана, курсивом, полупрозрачным белым текстом. Они привязаны к анимации: появляются одновременно со звуковым событием и исчезают через 2 секунды.

Для зрителей с нарушениями слуха субтитры — единственный способ узнать о звуке. Для всех остальных — это подтверждение: «Да, это был хлоп, а не случайный шум.»

Субтитры можно отключить в настройках. Переключатель: «Показывать звуковые подписи» (вкл/выкл).

ЗАКЛЮЧЕНИЕ
-----------

Звуковой дизайн для Canvas-мультиков — это работа в ограничениях. Canvas не рисует звук, Web Audio API сложен для новичков, браузеры блокируют автовоспроизведение. Но всё решаемо: генерация тонов для SFX, <audio> для BGM, визуальные подсказки для замены. В «Пирожках с нуля» звук — дополнительный канал, который усиливает визуал, но не является обязательным. Мультфильм работает без него. Но со звуком — оживает.
