ДИЗАЙН ПЕРСОНАЖА ДЛЯ CANVAS: ОТ ЭСКИЗА ДО АНИМАЦИИ
=====================================================

Введение
--------

Персонаж — это лицо проекта. Зритель запоминает не рецепт и не технику, а того, кто этот рецепт показывает. В проекте "Пирожки с нуля" пекарь-барашек стал главным героем, и его дизайн продуман до мелочей: от пропорций тела до анимации рук при замешивании теста. Эта статья рассказывает, как создать персонажа для Canvas-анимации — от первого эскиза до анимированных поз.


1. Пропорции карикатурного персонажа
-------------------------------------

Ключевое правило карикатурного дизайна: преувеличение для выразительности. В "Пирожках с нуля" используется пропорция 1:4.5 — голова составляет примерно 1/4.5 высоты тела. Это классическая "мультяшная" пропорция, которая делает персонажа милым и запоминающимся.

Почему именно 1:4.5:
- 1:2 (голова = половина тела) — слишком детский стиль, подходит для малышей.
- 1:3 (голова = треть) — стандартный мультяшный стиль (Микки Маус).
- 1:4.5 — баланс между карикатурой и реализмом, подходит для взрослой аудитории.
- 1:6 и выше — слишком реалистично, теряется мультяшность.

Конкретные пропорции барашка:
- Голова: эллипс шириной 60px, высотой 50px.
- Тело: прямоугольник с закруглёнными углами, ширина 80px, высота 90px.
- Руки: кривые Безье, длина ~40px.
- Ноги: прямоугольники, длина ~30px.
- Рога: два изогнутых конуса, высота ~20px.
- Уши: два эллипса, ширина 15px, высота 20px.


2. Детализация: цвет, одежда, лицо
------------------------------------

Цвет кожи и шерсти. Барашек — белый, но не "#FFFFFF". Чистый белый выглядит плоско и нереалистично. Используется тёплый белый "#F5F0E8" с лёгким кремовым оттенком. Для теней — серый "#E0DDD5". Эта разница создаёт объём.

Одежда. Пекарский фартук — главный аксессуар, сразу говорящий о профессии. Фартук рисуется поверх тела: прямоугольник с завязками за шеей. Цвет — тёплый коричневый "#8B6914" или красноватый "#C0392B", в зависимости от сцены.

Лицо. Минимализм — сила. Два круга для глаз (чёрные зрачки на белом фоне), дуга для рта, два круга для румянца на щеках. Сложная детализация лица на Canvas затрудняет анимацию и перегружает кадр.

Усы. Важнейший элемент узнаваемости. Два тонких изогнутых крючка над ртом. Именно усы делают барашка-пекаря unique — без них он будет похож на любого другого мультяшного баранчика.


3. Уникальные черты для узнаваемости
-------------------------------------

Узнаваемость персонажа строится на трёх вещах:

Силуэт. Даже в полной тьме зритель должен опознать барашка по форме. Рога, уши и фартук создают уникальный силуэт. При разработке我们在纸上先 нарисовали силуэт и убедились, что он читается.

Цветовая палитра. Ограниченная палитра из 4-5 цветов запоминается лучше, чем десятки оттенков. Барашек: белый (#F5F0E8), коричневый фартук (#8B6914), чёрные глаза, розовые щёки, чёрные усы.

Фирменный жест. Каждый запоминающийся персонаж имеет характерное движение. Барашек потирает руки перед работой и чешет затылок, когда задумывается. Эти жесты заложены в анимационные позы.


4. Анимация поз: idle, wave, knead, cut
-----------------------------------------

Для Canvas-анимации персонаж должен уметь выполнять набор базовых поз:

Idle (ожидание). Барашек стоит на месте, слегка покачиваясь. Реализация: синусоидальное изменение угла поворота тела ±2 градуса и лёгкое движение рук вверх-вниз. Частота: 0.5 Гц. Это создаёт эффект "дыхания".

Wave (приветствие). Правая рука поднимается и машет. Реализация: анимация угла руки от 0 до -45 градусов и обратно, с easing (плавным замедлением в крайних точках).

Knead (замешивание). Обе руки опускаются вниз и двигаются к центру, имитируя замешивание теста. Реализация: движение рук по эллиптической траектории с изменением расстояния между ними.

Cut (нарезка). Правая рука делает вертикальные движения вверх-вниз. Реализация: линейное движение руки с рывком вниз и плавным подъёмом.

Все анимации реализованы через ключевые кадры (keyframes) на Canvas:

  function animatePose(ctx, character, pose, progress) {
    const poseData = poses[pose];
    poseData.forEach(part => {
      const from = part.from;
      const to = part.to;
      const value = from + (to - from) * easeInOut(progress);
      drawPart(ctx, character, part.name, value);
    });
  }


5. Рисование на Canvas: ellipse, arc, bezier
---------------------------------------------

Основные инструменты для рисования персонажа:

Эллипсы — основа головы, тела, щёк:
  ctx.beginPath();
  ctx.ellipse(x, y, radiusX, radiusY, rotation, 0, Math.PI * 2);
  ctx.fill();

Дуги — глаза, рога, рот:
  ctx.arc(x, y, radius, startAngle, endAngle);

Кривые Безье — руки, усы, хвост:
  ctx.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y);

В "Пирожках с нуля" каждый элемент персонажа рисуется отдельной функцией, что позволяет анимировать его независимо:

  function drawSheep(ctx, pose) {
    drawBody(ctx, pose.body);
    drawHead(ctx, pose.head);
    drawArms(ctx, pose.leftArm, pose.rightArm);
    drawLegs(ctx, pose.leftLeg, pose.rightLeg);
    drawApron(ctx, pose.apron);
    drawHorns(ctx, pose.horns);
    drawFace(ctx, pose.face);
  }

Каждая подфункция принимает параметры позы и рисует элемент в нужном положении. Это分离关注点: логика анимации отделена от логики рисования.


Заключение
-----------

Дизайн персонажа для Canvas — это баланс между простотой и выразительностью. Минимум деталей, читаемый силуэт, запоминающаяся палитра — и персонаж живёт. В "Пирожках с нуля" барашек-пекарь стал не просто иллюстрацией, а полноценным актёром, чьи позы и жесты рассказывают историю. Canvas предоставляет все инструменты для рисования и анимации — остаётся только подключить воображение.
