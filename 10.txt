ТРАНЗИШЕНЫ: FADE, DISSOLVE И ДРУГИЕ ПЕРЕХОДЫ МЕЖДУ СЦЕНАМИ
===========================================================

Введение
--------

Переход между сценами — это невидимый клей, скрепляющий фильм. Плохой переход разрывает внимание зрителя, хороший — направляет его из одной эмоции в другую. В проекте "Пирожки с нуля" используются три типа переходов:fade to black, dissolve и wipe. Каждый выбирается не случайно, а в зависимости от драматургической задачи сцены. Эта статья разберёт типы переходов, их техническую реализацию на Canvas и влияние на восприятие ритма.


1. Типы переходов: fade to black, dissolve, wipe
-------------------------------------------------

Fade to black (затемнение). Самый простой и универсальный переход. Кадр плавно темнеет до чёрного, затем следующая сцена появляется из темноты. Ассоциация: конец главы, смена времени, пауза для дыхания.

Dissolve (растворение). Два кадра смешиваются: первый постепенно становится прозрачным, второй — непрозрачным. В какой-то момент оба видны одновременно. Асcoциация: связь между сценами, плавный переход, континуитет.

Wipe (вытеснение). Новый кадр "вытесняет" старый с одной стороны экрана. В классическом кино — полоса, в Canvas — любой геометрический паттерн. Ассоциация: динамика, перемещение в пространстве, смена локации.

Hard cut (жёсткая смена). Без перехода: один кадр мгновенно сменяется другим. Асcoциация: резкость, неожиданность, акцент.

В "Пирожках с нуля" распределение переходов:
- Fade to black: между актами (сцены 2→3, 5→6). Конец одной фазы, начало другой.
- Dissolve: между связанными сценами (сцены 1→2, 3→4). Процесс продолжается.
- Wipe: при смене локации (сцена 4→5: от стола к духовке). Перемещение в пространстве.
- Hard cut: внутри сцены для акцента (крупный план лица → общий план).


2. Реализация через globalAlpha
---------------------------------

Основной инструмент переходов на Canvas — globalAlpha, управляющий прозрачностью всего контекста:

Fade to black:
  function fadeToBlack(ctx, width, height, progress) {
    ctx.fillStyle = '#000000';
    ctx.globalAlpha = progress; // 0 → 1
    ctx.fillRect(0, 0, width, height);
    ctx.globalAlpha = 1;
  }

При progress = 0 экран прозрачный (видна текущая сцена). При progress = 1 экран полностью чёрный. Между ними — плавное затемнение.

Dissolve:
  function dissolve(ctx, oldFrame, newFrame, progress) {
    // Рисуем старый кадр
    ctx.globalAlpha = 1 - progress;
    ctx.drawImage(oldFrame, 0, 0);

    // Рисуем новый кадр
    ctx.globalAlpha = progress;
    ctx.drawImage(newFrame, 0, 0);

    ctx.globalAlpha = 1;
  }

При progress = 0.5 оба кадра видны с 50% прозрачностью — классический dissolve.

Wipe:
  function wipe(ctx, oldFrame, newFrame, progress, direction) {
    const x = width * progress;

    ctx.drawImage(oldFrame, 0, 0);

    ctx.save();
    ctx.beginPath();
    if (direction === 'left') {
      ctx.rect(0, 0, x, height);
    } else {
      ctx.rect(x, 0, width - x, height);
    }
    ctx.clip();
    ctx.drawImage(newFrame, 0, 0);
    ctx.restore();
  }

Новый кадр рисуется в clipped-области, которая расширяется от края к центру.


3. Триггеры: автоматический по таймеру
-----------------------------------------

В "Пирожках с нуля" переходы запускаются автоматически по таймлайну:

  const transitions = [
    { frame: 90, type: 'fade', duration: 30 },
    { frame: 210, type: 'dissolve', duration: 45 },
    { frame: 420, type: 'wipe', duration: 20, direction: 'left' },
    { frame: 510, type: 'fade', duration: 30 },
  ];

  function updateTransition(currentFrame) {
    const transition = transitions.find(
      t => currentFrame >= t.frame && currentFrame < t.frame + t.duration
    );

    if (transition) {
      const progress = (currentFrame - transition.frame) / transition.duration;
      applyTransition(transition.type, progress, transition.direction);
      return true; // переход активен
    }
    return false;
  }

Каждый переход имеет: кадр начала, тип, длительность и дополнительные параметры. Transition manager автоматически определяет, активен ли переход, и применяет нужный эффект.

Длительность переходов:
- Fade to black: 30 кадров (0.5 сек при 60 FPS). Быстрое, но заметное.
- Dissolve: 45 кадров (0.75 сек). Медленное, плавное.
- Wipe: 20 кадров (0.33 сек). Быстрое, динамичное.


4. Простые vs сложные переходы
--------------------------------

Простые переходы (fade, dissolve) — это инструмент повседневного использования. Они не привлекают внимания к себе, а направляют его из сцены в сцену. В "Пирожках с нуля" 70% переходов — простые.

Сложные переходы (wipe с паттерном, zoom-transition, page curl) — это акцентные инструменты. Их использование должно быть оправдано: например, wipe используется только при перемещении из одной зоны кухни в другую, чтобы зритель физически ощутил смену пространства.

Правило: сложный переход используется не более 2-3 раз за фильм. Частое использование превращает переход из инструмента в чину.

Пример сложного перехода — zoom-dissolve в "Пирожках с нуля":
  function zoomDissolve(ctx, oldFrame, newFrame, progress) {
    const zoom = 1 + progress * 0.3; // увеличение на 30%

    ctx.save();
    ctx.globalAlpha = 1 - progress;
    ctx.translate(width/2, height/2);
    ctx.scale(zoom, zoom);
    ctx.translate(-width/2, -height/2);
    ctx.drawImage(oldFrame, 0, 0);
    ctx.restore();

    ctx.globalAlpha = progress;
    ctx.drawImage(newFrame, 0, 0);
    ctx.globalAlpha = 1;
  }

Старый кадр увеличивается и растворяется, новый появляется. Используется для перехода к кульминации (сцена 5: пирожок из духовки).


5. Когда нужен транзишон, а когда — жёсткий cut
--------------------------------------------------

Правила выбора:

Используйтеfade when:
- Между крупными разделами (актами) фильма.
- Когда нужна пауза для дыхания зрителя.
- При смене эмоционального тона (от напряжения к спокойствию).

Используйте dissolve when:
- Между сценами, связанными по содержанию (один процесс).
- Когда время не останавливается, а продолжается.
- Для плавного перехода без резкого переключения внимания.

Используйте wipe when:
- При смене локации (от стола к духовке).
- Когда перемещение в пространстве — часть сюжета.
- Для динамичных, энергичных переходов.

Используйте hard cut when:
- Внутри сцены для смены ракурса (общий → крупный).
- Для акцента или неожиданности.
- Когда переход не нужен — действие идёт непрерывно.

В "Пирожках с нуля" hard cut используется внутри сцены замешивания: быстрая смена крупного плана рук на общий план стола. Это создаёт ощущение динамики без прерывания процесса.


6. Влияние на восприятие ритма
---------------------------------

Переходы — это пульс фильма:

Быстрые переходы (0.2-0.3 сек) → ускорение ритма, энергия, динамика. Используются в активных сценах (замес, духовка).

Медленные переходы (0.7-1.0 сек) → замедление ритма, пауза, размышление. Используются между актами и в финале.

Отсутствие перехода (hard cut) → мгновенное переключение, акцент, неожиданность. Используется для смены ракурса внутри сцены.

Сочетание переходов создаёт мета-ритм:
- Начало фильма: медленные fade (спокойное начало).
- Середина: быстрые dissolve и wipe (активное действие).
- Кульминация: zoom-dissolve (эмоциональный пик).
- Финал: медленный fade to black (спокойное завершение).

Эта динамика переходов соответствует динамике сцен и создаёт единый ритмический рисунок фильма.


Заключение
-----------

Транзишены — это невидимая режиссура. Правильный выбор перехода направляет зрительское внимание, создаёт ритм и связывает сцены в единое целое. В "Пирожках с нуля" каждый переход выбран осознанно: fade для пауз, dissolve для связей, wipe для перемещений, hard cut для акцентов. Canvas предоставляет простые инструменты (globalAlpha, clip, drawImage), а режиссёр решает, когда и как их использовать. Потому что переход — это не техническая задача, а художественное решение.
