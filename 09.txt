СУБТИТРЫ НА CANVAS: ТЕКСТ КАК ЧАСТЬ ВИЗУАЛЬНОГО РЯДА
======================================================

Введение
--------

Субтитры — это не техническая необходимость, а художественный инструмент. В проекте "Пирожки с нуля" текст на экране не просто дублирует звук — он является частью визуальной композиции: имеет цвет, позицию, анимацию появления и исчезновения. Ключевое решение проекта — отказ от HTML-оверлея в пользу отрисовки текста непосредственно на Canvas. Это дало полный контроль над каждым символом и его поведением.


1. Почему субтитры на canvas лучше HTML-оверлея
-------------------------------------------------

Стандартный подход к субтитрам в вебе — HTML-элемент <div> или <span>, позиционирований absolute поверх Canvas. Этот подход имеет три критических недостатка:

Отсутствие синхронизации. HTML-субтитры и Canvas-анимация — две независимые системы. Если анимация замедляется (из-за загрузки или тяжёлых вычислений), HTML-субтитры продолжают двигаться по своему таймеру. Возникает рассинхрон.

Ограничения стилизации. HTML-текст не может иметь нестандартные эффекты: обводка с градиентом, тень с анимацией, текстура. Всё это доступно только через CSS, который не интегрирован с Canvas.

Дополнительный слой DOM. Каждый HTML-субтитр — это DOM-узел. При большом количестве текста (особенно на мобильных) это создаёт нагрузку.

Отрисовка на Canvas решает все три проблемы: текст является частью того же контекста, что и анимация, полностью стилизуемый и не создающий дополнительных DOM-узлов.


2. Позиционирование, шрифты, фон
----------------------------------

Субтитры в "Пирожках с нуля" расположены в нижней трети экрана — стандартное место для caption:

Позиционирование:
  const SUBTITLE_Y = canvas.height * 0.82;
  const SUBTITLE_X = canvas.width / 2;

Текст центрирован по горизонтали и размещён на 82% высоты Canvas. Это оставляет место для таймера в верхнем углу и не перекрывает основное действие в центре.

Шрифт:
  ctx.font = 'bold 18px "Segoe UI", Arial, sans-serif';

Используетсяsans-serif шрифт для максимальной читаемости. Размер 18px — баланс между читаемостью и компактностью. Жирный (bold) вес для контраста.

Фон субтитров:
  ctx.fillStyle = 'rgba(0, 0, 0, 0.6)';
  roundRect(ctx, x - textWidth/2 - 10, y - 14, textWidth + 20, 28, 5);
  ctx.fill();

Полупрозрачный чёрный фон с закруглёнными углами. Прозрачность 0.6 позволяет видеть анимацию за текстом, но обеспечивает контраст для читаемости.


3. Два голоса: Шеф (красный) и Диктор (синий)
-----------------------------------------------

В проекте два "рассказчика" с разными характерами:

Шеф (барашек-пекарь). Говорит от первого лица, даёт советы и комментирует процесс. Его субтитры — красноватые (#E74C3C) с белым контуром. Ассоциация: тепло, энергия, экспертность.

  // Субтитры Шефа
  ctx.fillStyle = '#E74C3C';
  ctx.strokeStyle = '#FFFFFF';
  ctx.lineWidth = 2;

Диктор (закадровый голос). Объясняет рецептуру и технику. Его субтитры — синие (#3498DB) с белым контуром. Ассоциация: спокойствие, надёжность, объективность.

  // Субтитры Диктора
  ctx.fillStyle = '#3498DB';
  ctx.strokeStyle = '#FFFFFF';
  ctx.lineWidth = 2;

Визуальное разделение голосов позволяет зрителю мгновенно понять, кто говорит, даже без звука. Это критично для просмотра в шумной среде или без наушников.


4. Fade-in/fade-out текста
---------------------------

Появление и исчезновение текста — не мгновенное, а анимированное:

Fade-in (появление):
  function drawSubtitle(text, opacity) {
    ctx.globalAlpha = opacity;
    // рисуем текст
    ctx.globalAlpha = 1;
  }

  // Анимация fade-in за 15 кадров (~0.25 сек)
  if (subtitleProgress < 15) {
    opacity = subtitleProgress / 15;
  }

Fade-out (исчезновение):
  // Анимация fade-out за 10 кадров (~0.17 сек)
  if (timeRemaining < 10) {
    opacity = timeRemaining / 10;
  }

Fade-in медленнее fade-out (0.25 сек vs 0.17 сек) — текст появляется плавно, чтобы зритель успел начать читать, но исчезает быстро, чтобы не мешать следующему кадру.

Синхронизация с таймлайном:
  const subtitleTimeline = [
    { start: 0, end: 90, text: 'Доброе утро! Сегодня мы печём пирожки.', voice: 'chef' },
    { start: 91, end: 150, text: 'Нам понадобится мука, вода, дрожжи и соль.', voice: 'narrator' },
    { start: 151, end: 210, text: 'Начнём с замешивания теста.', voice: 'chef' },
  ];

Каждый субтитр привязан к кадрам (frames), а не к секундам. Это гарантирует синхронизацию с анимацией независимо от FPS.


5. Читаемость на разных размерах экрана
-----------------------------------------

Canvas-субтитры должны читаться и на 27" мониторе, и на 5" смартфоне. Решение — адаптивный размер шрифта:

  function getAdaptiveFontSize() {
    const minDimension = Math.min(canvas.width, canvas.height);
    return Math.max(14, Math.floor(minDimension * 0.035));
  }

На экране 1920x1080: шрифт ~38px. На экране 375x667 (iPhone): шрифт ~14px. Минимальный порог — 14px, чтобы текст оставался читаемым.

Дополнительно:
- Контур (stroke) текста всегда виден на любом фоне.
- Фон субтитра масштабируется вместе с текстом.
- Межстрочный интервал: 1.4x размера шрифта для многострочных субтитров.

Проверка читаемости:
  // Проверяем, помещается ли текст в одну строку
  const metrics = ctx.measureText(text);
  if (metrics.width > canvas.width * 0.8) {
    // Разбиваем на две строки
    text = splitTextToLines(text, canvas.width * 0.8);
  }


6. Синхронизация с таймлайном
-------------------------------

Каждый субтитр привязан к конкретному моменту анимационного таймлайна:

  class SubtitleManager {
    constructor(timeline) {
      this.timeline = timeline;
      this.currentFrame = 0;
      this.currentOpacity = 0;
    }

    update(frame) {
      this.currentFrame = frame;
      const entry = this.timeline.find(
        e => frame >= e.start && frame <= e.end
      );

      if (entry) {
        const framesIn = frame - entry.start;
        const framesOut = entry.end - frame;
        this.currentOpacity = Math.min(framesIn / 15, framesOut / 10, 1);
        this.currentText = entry.text;
        this.currentVoice = entry.voice;
      } else {
        this.currentOpacity = 0;
      }
    }

    draw(ctx) {
      if (this.currentOpacity <= 0) return;
      drawSubtitle(ctx, this.currentText, this.currentVoice, this.currentOpacity);
    }
  }

Этот менеджер автоматически рассчитывает opacity (fade-in/fade-out), определяет голос и рисует субтитр. Таймлайн хранит все субтитры в одном массиве, что упрощает管理和 редактирование.


Заключение
-----------

Субтитры на Canvas — это не замена, а upgrade по сравнению с HTML-оверлеем. Полный контроль над позицией, стилем, анимацией и синхронизацией позволяет сделать текст неотъемлемой частью визуального ряда. В "Пирожках с нуля" два голоса — Шеф и Диктор — разговаривают разными цветами, появляются и исчезают в унисон с анимацией. Canvas превращает субтитры из технической надобности в художественный инструмент.
