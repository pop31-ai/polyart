ЭПИЗОДНЫЕ ЗАГОЛОВКИ: СТРУКТУРА НАРРАТИВА ЧЕРЕЗ ТИТРЫ
═════════════════════════════════════════════════════════

Введение
────────

Любой рассказ — даже анимированный мультик на Canvas — нуждается в структуре. Зрителю необходимо понимать, где он находится в повествовании: начало, развитие, кульминация, развязка. В кино это решается через монтажные склейки, в мультфильмах — через эпизодные заголовки. Проект «Пирожки с нуля» использует систему текстовых титров-разделителей, которые сигнализируют о переходе между эпизодами и задают настроение каждого блока.


Каждый эпизод — отдельный блок с заголовком
───────────────────────────────────────────

Структура мультика разбита на логические эпизоды:

1. ПРОЛОГ — начальная экспозиция, знакомство с персонажем и пространством
2. ПРОБУЖДЕНИЕ — кухня оживает, начинается процесс
3. СМЕШЕНИЕ — подготовка теста, ингредиенты
4. ФОРМОВКА — лепка пирожков, детализация процесса
5. ВЫПЕЧКА — ожидание, трансформация, Maillard reaction
6. ФИНАЛ — результат, эмоции, подведение итогов

Каждый эпизод — это отдельная сцена со своим mood-состоянием, цветовой палитрой и набором анимаций. Заголовок появляется перед началом эпизода и исчезает через заданное время.

Заголовок — это не просто текст. Это визуальный маркер, который:

- Даёт зрителю ориентир в структуре
- Задаёт эмоциональный тон предстоящего эпизода
- Создаёт паузу между сценами для «переваривания» информации
- Позволяет отслеживать прогресс через прогресс-бар


Визуальное оформление
─────────────────────

Заголовки оформлены единообразно, но с вариациями для каждого эпизода:

Градиентный фон:
- Полупрозрачный overlay поверх основной сцены
- Цвет градиента зависит от mood эпизода
- cheerful: rgba(255, 180, 100, 0.7) → rgba(255, 220, 150, 0.3)
- dramatic: rgba(30, 30, 50, 0.8) → rgba(60, 40, 80, 0.4)
- romantic: rgba(200, 100, 130, 0.7) → rgba(255, 150, 180, 0.3)

Анимация появления:
- Fade-in: 0 → 1 за 400мс
- Масштаб: 0.9 → 1.0 за 500мс
- Мягкое появление через ease-out

const titleAnimation = {
  fadeIn: 400,
  scaleIn: 500,
  hold: 8000,
  fadeOut: 400
};

Шрифт: крупный, разборчивый, с тенью для контрастности. Типографика соответствует стилю проекта — дружелюбный, но информативный.

function drawEpisodeTitle(ctx, text, progress) {
  const alpha = progress < 0.1 ? progress / 0.1 :
                progress > 0.9 ? (1 - progress) / 0.1 : 1;
  const scale = 0.9 + 0.1 * Math.min(progress * 5, 1);

  ctx.save();
  ctx.globalAlpha = alpha;
  ctx.translate(W/2, H/2);
  ctx.scale(scale, scale);
  ctx.fillStyle = '#fff';
  ctx.shadowColor = 'rgba(0,0,0,0.5)';
  ctx.shadowBlur = 10;
  ctx.font = 'bold 48px "Comfortaa", sans-serif';
  ctx.textAlign = 'center';
  ctx.fillText(text, 0, 0);
  ctx.restore();
}


Тайминг: 8 секунд на экране
────────────────────────────

Время отображения заголовка — 8 секунд. Почему именно столько:

- 2 секунды: осознание наличия заголовка
- 3 секунды: чтение и понимание
- 2 секунды: эмоциональная подготовка к эпизоду
- 1 секунда: плавное завершение

Этот тайминг выверен эмпирически. Слишком короткий заголовок (3-4 сек) не успевает считаться, слишком длинный (12+ сек) утомляет. 8 секунд — золотая середина.

В коде это реализовано через этапы:

function updateTitle(t) {
  if (t < 400) return 'fadeIn';        // 0-0.4с
  if (t < 7600) return 'hold';          // 0.4-7.6с
  if (t < 8000) return 'fadeOut';       // 7.6-8.0с
  return 'hidden';
}


Функция: сигнализация перехода
──────────────────────────────

Эпизодные заголовки выполняют несколько функций одновременно:

Структурная:
- Разделяют мультфильм на логические блоки
- Позволяют зрителю понять, в какой части истории он находится
- Создают ритм: действие → пауза → действие

Эмоциональная:
- Задают тон предстоящего эпизода через цвет и текст
- Создают момент тишины перед важными сценами
- Позволяют эмоционально «переключиться»

Навигационная:
- Прогресс-бар обновляется при появлении заголовка
- Зритель видит, что эпизод завершён и начинается следующий
- В будущем: возможность перейти к конкретному эпизоду через меню

Заголовки также служат точками синхронизации с аудио (если оно будет добавлено) и маркерами для сохранения прогресса.


Заключение
──────────

Эпизодные заголовки —看似 простой элемент, но критически важный для структуры нарратива в анимированном мультике. Система титров проекта «Пирожки с нуля» превращает линейную последовательность сцен в чётко структурированное повествование с понятными границами эпизодов. Визуальное оформление, тайминг и эмоциональная функция заголовков работают вместе, создавая удобный и красивый интерфейс для зрителя.
