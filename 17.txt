МИНИ-ТАЙМЛАЙН: НАВИГАЦИЯ ПО СЦЕНАМ ВИЗУАЛЬНО
================================================

ВВЕДЕНИЕ
--------

В мультфильме, который длится несколько минут и состоит из восьми сцен, зритель должен понимать, где он находится и сколько осталось. Мини-таймлайн — это визуальный навигатор, который решает эту задачу. Он расположен в нижней части экрана и представляет собой полосу из восьми цветных блоков. Каждый блок — одна сцена. Простая, но продуманная система навигации, которая превращает линейный просмотр в осознанный маршрут.

СТРУКТУРА ТАЙМЛАЙНА: ВОСЕМЬ БЛОКОВ
-------------------------------------

Таймлайн — это горизонтальная полоса длиной 400 пикселей (адаптивно к ширине экрана). Она разделена на 8 равных блоков по 48 пикселей каждый (с 4-пиксельными зазорами между ними).

Каждый блок соответствует одной сцене:

1. Вступление (приветствие, обзор рецепта).
2. Замес теста (процесс).
3. Подъём теста (таймлапс).
4. Обминка и формовка (разделение на части).
5. Нарезка и формовка пирожков (жесты).
6. Начинка (добавление ингредиентов).
7. Выпечка (духовка, таймер).
8. Финал (результат, дегустация).

Каждый блок подписан: цифра (номер сцены) и иконка (маленький эмодзи). Например, блок 2 — «🤲 Замес», блок 7 — «🔥 Выпечка». Иконки помогают быстрее ориентироваться, чем текст.

ЦВЕТА, HOVER-ЭФФЕКТЫ, ACTIVE-STATE
-------------------------------------

Цвета блоков — визуальный код состояния:

Неактивный (просмотрен) — тёмно-зелёный (#2E7D32). Зритель уже видел эту сцену. Зелёный = «выполнено».

Активный (текущий) — яркий оранжевый (#FF9800). Зритель сейчас здесь. Оранжевый = «внимание, сейчас!».

Будущий (ещё не просмотрен) — серый (#9E9E9E). Эта сцена впереди. Серый = «ещё не время».

Hover-эффект: при наведении мыши блок слегка увеличивается (scale 1.1 за 0.15 секунды) и появляется тень (box-shadow 0 0 8px rgba(255,152,0,0.5)). Это подсказка: «Этот блок кликабелен».

Active-state: текущий блок пульсирует. Alpha колеблется от 0.8 до 1.0 с частотой 2 Гц. Это привлекает внимание к текущей позиции и создаёт ощущение «живого» интерфейса.

ПРОГРЕСС-БАР ВНУТРИ КАЖДОГО БЛОКА
-------------------------------------

Каждый блок содержит мини-прогресс-бар — горизонтальную полосу внизу. Высота: 3 пикселя. Цвет: белый (#FFFFFF) с alpha 0.5.

Прогресс-бар заполняется слева направо по мере прохождения сцены. Формула: progress = currentTime / sceneDuration. Когда сцена завершена — полоса полностью белая. Когда ещё не начата — полностью прозрачная.

Это двойная информация: и цвет блока (завершена/текущая/будущая), и прогресс внутри (сколько прошло). Зритель одним взглядом понимает: «Я на сцене 5, и она на 60% прошла.»

КЛИКАБЕЛЬНОСТЬ: ПЕРЕХОД К СЦЕНЕ
---------------------------------

Таймлайн — не просто визуализация. Это активный контрол. Клик по любому блоку запускает переход к соответствующей сцене.

При клике происходит:

1. Текущая анимация останавливается (clearInterval/cancelAnimationFrame).
2. Время сцены устанавливается в 0 (или в начало при повторном просмотре).
3. Все визуальные элементы сцены перерисовываются для нового начального состояния.
4. Таймер обновляется.
5. Запускается анимация новой сцены.

Ограничение: нельзя перейти к ещё не разблокированной сцене. Если зритель просмотрел сцены 1-3 и кликает на сцену 5 — ничего не происходит. Серый блок не кликабелен. Это мотивирует просмотр по порядку.

Исключение: после завершения мультфильма все блоки становятся зелёными и кликабельными. Это режим повторного просмотра.

ИНТЕГРАЦИЯ С ОСНОВНЫМ ТАЙМЕРОМ
---------------------------------

Таймлайн синхронизирован с основным таймером анимации. Каждый кадр (requestAnimationFrame) обновляется прогресс текущего блока.

Связь双向:
- Таймер → таймлайн: прогресс-бар текущего блока обновляется.
- Таймлайн → таймер: клик по блоку переключает таймер на нужную сцену.

Когда сцена завершается (прогресс = 100%), блок меняет цвет с оранжевого на зелёный, и следующий блок «просыпается» (серый → оранжевый). Это анимированный переход: цвет меняется за 0.3 секунды (ease-in-out).

CSS: FLEX, TRANSITIONS
------------------------

Таймлайн реализован через CSS flexbox:

Контейнер — display: flex, justify-content: center, gap: 4px. Центрирует блоки и задаёт расстояние.

Блок — flex: 1, height: 48px, border-radius: 8px. Flex: 1 делает все блоки одинаковой ширины. Border-radius — скруглённые углы для мягкости.

Прогресс-бар — position: absolute, bottom: 4px, height: 3px, transition: width 0.3s ease. Анимация заполнения через CSS transition.

Hover — transition: transform 0.15s ease, box-shadow 0.15s ease. Плавное увеличение и тень.

Active — animation: pulse 0.5s ease infinite. CSS-анимация пульсации для текущего блока.

Всё это — чистый CSS без JavaScript-анимаций (кроме цвета блока). CSS transitions быстрее и плавнее, чем ручные анимации через requestAnimationFrame.

АДАПТИВНОСТЬ
--------------

На маленьких экранах (мобильные устройства) таймлайн адаптируется:

- Ширина: 100% ширины экрана (с отступами 16px по бокам).
- Блоки: уменьшаются до 36×36 пикселей.
- Иконки: скрываются (остаются только цифры).
- Прогресс-бар: уменьшается до 2 пикселей.

На больших экранах (десктоп) таймлайн расширяется:
- Максимальная ширина: 600 пикселей.
- Блоки: увеличиваются до 60×60 пикселей.
- Иконки + текст: отображаются полностью.

Адаптивность реализована через media queries в CSS и проверку window.innerWidth в JavaScript.

ЗАКЛЮЧЕНИЕ
-----------

Мини-таймлайн в «Пирожках с нуля» — это пример того, как простой UI-элемент решает множество задач. Он информирует (где я), мотивирует (сколько осталось), структурирует (восемь сцен) и даёт контроль (клик для перехода). Всего 8 блоков, 48 пикселей высотой — но за этим стоит продуманный дизайн, который делает просмотр осознанным и удобным.
