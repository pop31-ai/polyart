CANVAS 2D API: ПОЛНЫЙ ОБЗОР ВОЗМОЖНОСТЕЙ ДЛЯ АНИМАТОРА
======================================================

Введение
--------

Canvas 2D API — это JavaScript-интерфейс для рисования двумерной графики прямо в браузере. Для аниматора это equivalent-of Photoshop, только программный: каждая линия, каждый цвет, каждый эффект создаётся кодом. В проекте "Пирожки с нуля" Canvas 2D — это основа всего визуального ряда. Эта статья даст полный обзор ключевых возможностей API и покажет, как они применяются на практике.


1. Контекст рисования и основные методы
----------------------------------------

Всё начинается с получения контекста рисования. Строка const ctx = canvas.getContext('2d') — это как открыть альбом и взять кисть. После этого вам доступны десятки методов для рисования.

Основные геометрические примитивы:

Прямоугольники是最简单的形体:
  ctx.fillRect(x, y, width, height) — залитый прямоугольник.
  ctx.strokeRect(x, y, width, height) — контур прямоугольника.
  ctx.clearRect(x, y, width, height) — очистка области.

Дуги и круги:
  ctx.arc(x, y, radius, startAngle, endAngle, counterclockwise) — рисует дугу или полный круг. В "Пирожках с нуля" голова барашка рисуется именно этой командой: ctx.arc(100, 80, 40, 0, Math.PI * 2).

Пути (Paths) — самая мощная возможность:
  ctx.beginPath() — начало нового пути.
  ctx.moveTo(x, y) — перемещение "пера".
  ctx.lineTo(x, y) — линия до точки.
  ctx.quadraticCurveTo(cpx, cpy, x, y) — кривая второго порядка.
  ctx.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y) — кривая третьего порядка.
  ctx.closePath() — замкнуть путь.

В "Пирожках с нуля" кривые Безье используются повсюду: от контура тела барашка до формы пирожка. Кривые Безье позволяют создавать плавные, естественные формы, которые невозможно получить простыми кругами и прямоугольниками.


2. Градиенты, тени и compositing
---------------------------------

Градиенты превращают плоскую графику в объёмную:

Линейный градиент:
  const gradient = ctx.createLinearGradient(x0, y0, x1, y1);
  gradient.addColorStop(0, 'white');
  gradient.addColorStop(1, 'black');
  ctx.fillStyle = gradient;

Радиальный градиент:
  const gradient = ctx.createRadialGradient(x0, y0, r0, x1, y1, r1);

В проекте "Пирожки с нуля" градиенты используются для имитации объёма: радиальный градиент на шаре барашка создаёт эффект трёхмерности, а линейный градиент на фоне сцены — глубину пространства.

Тени добавляют реализм:
  ctx.shadowColor = 'rgba(0, 0, 0, 0.3)';
  ctx.shadowBlur = 10;
  ctx.shadowOffsetX = 5;
  ctx.shadowOffsetY = 5;

Compositing управляет тем, как новые элементы взаимодействуют со старыми:
  ctx.globalCompositeOperation = 'source-over' — обычное наложение.
  ctx.globalCompositeOperation = 'multiply' — умножение цветов.
  ctx.globalCompositeOperation = 'screen' — осветление.

В "Пирожках с нуля" multiply используется для создания теней на объектах, а screen — для свечения горячего пирожка из духовки.


3. Текст на Canvas
------------------

Canvas позволяет рисовать текст программно, что критически важно для информационных блоков:

  ctx.font = 'bold 24px Arial';
  ctx.fillStyle = '#333';
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText('Мука — 500г', x, y);

Ключевые свойства:
- font — размер, жирность, шрифт.
- textAlign — выравнивание: left, center, right.
- textBaseline — вертикальное выравнивание: top, middle, bottom.
- fillStyle — цвет заливки текста.
- strokeStyle — цвет обводки текста (обводка добавляет читаемость на ярком фоне).

В "Пирожках с нуля" текст используется в двух функциях: как субтитры (в верхней или нижней части экрана) и как инфографика (списки ингредиентов, таймеры). Для субтитров используется strokeStyle для контура, чтобы текст читался на любом фоне.


4. Оптимизация: requestAnimationFrame vs setInterval
-----------------------------------------------------

Правильный выбор метода обновления кадров — ключ к плавной анимации.

setInterval и setTimeout — старый подход. Они не привязаны к частоте обновления экрана и могут вызывать пропуск кадров или дублирование:

  setInterval(() => { draw(); }, 16); // ~60 FPS, но неточные

requestAnimationFrame — современный стандарт. Браузер автоматически подстраивает частоту под refresh rate монитора и приостанавливает анимацию, когда вкладка не видна:

  function animate() {
    draw();
    requestAnimationFrame(animate);
  }
  requestAnimationFrame(animate);

В "Пирожках с нуля" используется именно requestAnimationFrame. Это критично, потому что:
- Анимация идёт 15 минут, и при сворачивании вкладки таймер не должен "улетать".
- Частота кадров автоматически подстраивается под 60 или 144 Hz монитор.
- Экономия батареи на ноутбуках — при неактивной вкладке анимация не потребляет ресурсы.


5. Ограничения Canvas и их обходные пути
-----------------------------------------

Canvas 2D API имеет несколько важных ограничений:

Отсутствие DOM. Canvas не создаёт объектов в DOM-дереве. Это значит, что:
- Нет событий клика по отдельным элементам (нужно вручную определять попадание мыши).
- Нет доступности для скринридеров (нужно дублировать текст в HTML).
- Нет SEO-индексации контента.

Разрешение. Canvas имеет фиксированное разрешение, заданное атрибутами width и height. При изменении размера окна Canvas не масштабируется автоматически. Решение: умножать разрешение на devicePixelRatio.

  const dpr = window.devicePixelRatio || 1;
  canvas.width = width * dpr;
  canvas.height = height * dpr;
  ctx.scale(dpr, dpr);

Память. Каждый вызов fillRect, arc или bezierCurveTo сохраняет команду в буфере. При большом количестве элементов буфер переполняется. Решение: очищать Canvas перед каждым кадром (clearRect) и рисовать только видимые элементы.

В "Пирожках с нуля" все эти ограничения учтены: используется devicePixelRatio для Retina-экранов, Canvas очищается перед каждым кадром, а текст дублируется в HTML для accessibility.


6. Пример кода: рисуем круг с градиентом
-----------------------------------------

Вот как выглядит рисование объекта из "Пирожков с нуля" — головы барашка с радиальным градиентом:

  function drawSheepHead(ctx, x, y) {
    // Создаём радиальный градиент для объёма
    const gradient = ctx.createRadialGradient(
      x - 10, y - 10, 5,   // внутренний круг (ближе к свету)
      x, y, 40               // внешний круг
    );
    gradient.addColorStop(0, '#FFFFFF');  // белый — высветление
    gradient.addColorStop(1, '#E0E0E0');  // серый — тень

    ctx.beginPath();
    ctx.arc(x, y, 40, 0, Math.PI * 2);  // круг радиусом 40
    ctx.fillStyle = gradient;
    ctx.fill();

    // Добавляем тень
    ctx.shadowColor = 'rgba(0, 0, 0, 0.2)';
    ctx.shadowBlur = 8;
    ctx.shadowOffsetY = 4;
  }

Этот пример демонстрирует ключевой принцип полиарта: один метод ctx.arc создаёт форму, градиент добавляет объём, а тени — реализм. Всё это — три строки настройки и одна команда отрисовки.


Заключение
-----------

Canvas 2D API — это достаточно мощный инструмент для создания сложных анимаций, но при этом достаточно простой для быстрого прототипирования. В проекте "Пирожки с нуля" он показал свою зрелость: от рисования простых геометрических фигур до создания полноценного анимированного фильма. Освоив основные методы, градиенты, тени и оптимизацию, аниматор получает в своё распоряжение универсальный инструмент, ограниченный только воображением.
