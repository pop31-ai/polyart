# Гипотезы PolyArt (внешняя лаборатория)

> Additive-only: этот каталог ничего не изменяет в каноническом репозитории
> [pop31-ai/polyart](https://github.com/pop31-ai/polyart) — он готовит
> материалы в его стиле для возможного апстрима в `articles/`.

## Формат гипотезы

Каждый файл `Hnn_*.md` — одна гипотеза:

| Раздел | Смысл |
|---|---|
| **Гипотеза** | утверждение одним абзацем, фальсифицируемое |
| **Упоминания** | на какие материалы polyart опираемся (файл → что берём) |
| **Подходы** | 2–3 варианта реализации, сравнение |
| **Код** | референс-набросок (не претендует на финальный API) |
| **Как проверить** | измеримый протокол (обычно через `polyart_cv_test`) |
| **Риски** | что может пойти не так |
| **Статус** | idea / prototyped / needs-review |

## Почему отдельным каталогом

Гипотезы должны быть дешёвыми: их можно добавлять, оспаривать и снимать,
не трогая ядро. Апстрим кандидатов в `articles/` — отдельное решение
мейнтейнера; каждый документ уже оформлен по домовым правилам:
абстракт, нумерованные разделы, код, «См. также».
